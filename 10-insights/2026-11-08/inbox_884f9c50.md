## Your Company Has No Model of Itself. Agents Can Build One - Joao Wenzel, Citadel Securities

用 agent 持續整合簡報、Slack、PR 等資料，建立一個像「公司記憶」的組織世界模型，找出公司實際狀況與報告不符之處。

**Why** 公司裡「什麼都知道」的資深員工無法擴展且沒人記錄；簡報常有「西瓜專案」（外綠內紅），單純 RAG 只撈幾則訊息就判定綠燈，缺少脈絡。

**How** 借用機器人學的 state estimator 概念：Update→Age→Observe→Grade→Correct 迴圈，依訊號的時效、來源可信度、與其他感測器是否一致更新信念；用 XML 加視覺模型解析簡報，不修改過往月份只往前累積；以專家 agent 拆解素材取代一次丟給模型，並以回測驗證預測力。

**What** Citadel Securities 的 Joao Wenzel 分享已累積三年的專案紀錄：約半數交付日期在 2 個月內變動，其中 90% 往後延；拆分專家 agent 工作流後有洞察的更新量超過兩倍；回測顯示被標記的綠燈專案轉黃或紅的機率是兩倍。系統用於引導領導層會議（從簡報與證據不一致處切入）並產出每週報告。

### 重點
- 以 state estimator 看待公司模型：依訊號時效、來源可信度、跨感測器一致性更新信念，不是單純索引與 RAG
- 三年資料顯示約半數交付日期在 2 個月內變動，其中 90% 變更後晚於原訂；專家 agent 工作流使有洞察的更新量超過 2 倍
- 回測（以過去日期快照比對後續標籤）：被標記的綠燈專案轉黃或紅的機率為兩倍；缺訊號不能當成零，須記錄感測器最後正常時間

## Google Cloud Adds Self-Managed VMware Cloud Foundation on Bare Metal

Google Cloud 讓企業能在專屬實體伺服器上自己管理一整套 VMware 環境。

**Why** 部分企業想保有對 VMware 底層的完整控制權，而不是交給 Google 代管。

**How** 在 Google Z3 專屬 bare metal 上執行 VMware Cloud Foundation 9.x，客戶擁有 ESXi、vCenter、NSX 的 root 權限；生命週期管理、patch 與 Broadcom 授權都回到客戶手上。

**What** Google Cloud 的 self-managed VMware Cloud Foundation 正式 GA，涵蓋 22 個 region，與 Google 代管的 VMware Engine 並存，功能上對標 AWS 與 Oracle 由客戶自行營運的方案。

### 重點
- VMware Cloud Foundation 9.x 跑在 Z3 bare metal，GA 於 22 個 region
- 客戶擁有 ESXi、vCenter、NSX 的 root 存取權
- 生命週期、patching 與 Broadcom 授權責任轉回客戶，與 Google 代管的 VMware Engine 並存

Google Cloud has made a self-managed VMware solution generally available, running VMware Cloud Foundation 9.x on dedicated Z3 bare metal with root access across ESXi, vCenter and NSX in 22 regions. It sits beside the Google-managed VMware Engine and matches customer-operated offerings from AWS and Oracle, shifting lifecycle, patching and Broadcom licensing back to the customer. By Steef-Jan Wiggers

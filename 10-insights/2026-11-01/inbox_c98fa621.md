## Most of Your Docs Readers Are Now AI Agents - Hahnbee Lee, Mintlify & Lincoln Murr, Coinbase

文件和 API 的主要讀者正在從人變成 AI agent，所以內容要做給 agent 看。

**Why** 程式 agent 讓工程速度大增，agent 讀文件時只要遇到一點阻力就會停下或換產品，不會花力氣 debug。

**How** Mintlify 認為重點從視覺設計轉向頁面大小（吃多少 context window）、內容正確性與自動化防過期；Coinbase 則把整個業務做成 API，再視需要包成 MCP 或 CLI，並讓 agent 持有錢包以微額付款。

**What** Mintlify 旗下文件站的 agent 流量佔比從年初約 10% 升到接近 80%，人類流量並未下降。Coinbase 表示過去一年約有 1 億筆 agent 交易在鏈上發生，主要是 agent 購買 API 服務，並推動由 Cloudflare、Stripe、Mastercard、Visa 等共同治理的 x402 支付標準。

### 重點
- Mintlify 文件站 agent 流量佔比：年初約 10%，現在接近 80%，人類流量沒有下降
- 對 agent 而言重要的是頁面大小（context window 占用）、內容正確、避免過期的自動化，而非前端設計
- Coinbase 觀點：API 是底層，MCP 與 CLI 是外包裝；過去一年約 1 億筆鏈上 agent 交易，x402 支付標準讓 agent 可逐次付費、免申請 API key

## Query, Key, Value: The Library Trip Behind Every LLM

用圖書館比喻解釋 Query、Key、Value，這是讓語言模型判斷「它」指涉對象的核心機制。

**Why** 模型需要判斷句中詞彙之間的關聯，例如代名詞指的是哪個名詞。

**How** 以 Query 與 Key 比對相關性，再取出對應的 Value 作為資訊（文章以圖書館取書作比喻）。

**What** 這是 Attention 機制的入門解說，摘要未提供公式或程式實作。

### 重點
- Query 對 Key 比對相關性，取回對應的 Value
- 以代名詞指涉為例說明注意力的作用

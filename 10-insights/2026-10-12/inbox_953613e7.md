## v0.56.0

Repowise v0.56.0 是以「讓 coding agent 更有效使用程式碼索引」為主軸的更新。新增 `repowise update --working-tree` 以索引尚未 commit 的工作內容（#3095）、skeleton+ 檢視（#3097）、列出某符號所有 edit sites 並對照即時檔案驗證（#3126）、搜尋可回傳符合的原始碼行並接受 grep 風格 pattern 參數（#3128、#3131）。Keyless（無 LLM key）模式下改為提供排序後的檔案清單，並優先排列 stack trace 或問題中提到的識別字所指檔案（#3116、#3137）。Agent 整合方面新增 GitHub Copilot CLI 與 Kiro 目標、VS Code 的 Copilot 指示（#3173），並以 preToolUse hook 改寫 Cursor shell 指令（#3177）；provider 預設改為 claude-haiku-5-5（#3093），並以 ProviderSpec 統一宣告 LLM provider（#3168）。另有 web i18n 基礎與 zh-CN 語系（#3129、#3151），Gemini tool schema 移除 additionalProperties（#3064）。原文在中途被截斷。

### 重點
- `repowise update --working-tree` 可索引未 commit 的工作內容（#3095），並在僅有 working-tree 變更時跳過 history 與分析階段（#3107）
- 搜尋與 MCP：回傳符合的原始碼行、接受 grep 風格 pattern、列出符號的所有 edit sites 並以即時檔案驗證（#3128、#3131、#3126）
- 新增 GitHub Copilot CLI 與 Kiro 目標（#3173）、Cursor preToolUse hook 改寫 shell 指令（#3177）；anthropic 與 claude_cli 預設模型改為 claude-haiku-5-5（#3093）

## Why this CTO still loves OpenClaw on a Mac Mini

一位 CTO 把 OpenClaw 當成專屬 Jarvis，拆成多個分工明確的小 agent，替他處理審批、訂餐、打電話與智慧家居這些瑣事。

**Why** 他身為主管常是團隊審批的瓶頸，也想消除生活中哪怕只有 1% 的惱人小事。

**How** 用 soul 檔設定護欄與人格，一個 master agent 加多個 micro agent 負責路由，避免單一 agent 在不同角色間產生幻覺；主要用 WhatsApp 與 TUI 直接對話來建構，需要寫程式時由 OpenClaw 自行呼叫 Claude Code 等工具。

**What** 講者是 Inovvisir 的 CTO Ankit Maheswari，OpenClaw 跑在舊金山家中的 Mac Mini 上，用 Opus 5.5，每月 Anthropic 費用約 $500–600。用例包括每 4 小時彙整待審履歷、透過 n8n 處理 Navan/Coupa 的差旅與費用審批、用 Bland AI 打電話催同事或訂位與談判、在 9:30 確認後自動訂午餐、反向工程智慧家居協定並依下班位置自動開冷氣。他另一台 Mac Mini 跑 GLM 5.2 Flash（230K context），適合摘要與 email cron，但操作瀏覽器會失敗；曾有 agent 在他搭機時自動核准差旅，因此強調護欄。

### 重點
- 多 agent 架構：一個 master soul MD 加多個專責 soul（語音通話、健康餐點、email 分流、CTO digest），因單一 agent 在餐廳/同事/預約等不同通話人格間會幻覺與遺忘
- 成本與本地模型：Jarvis 每月 Anthropic 帳單約 $500–600；GLM 5.2 Flash（230K context、可 tool calling）能做摘要與 email cron，但瀏覽器截圖操作會失敗
- 護欄的必要性：agent 在他飛行中自動核准了即將過期的差旅申請（符合預算、屬必要客戶差旅），所以需明確定義哪些事可自動核准、哪些（如職缺）不行

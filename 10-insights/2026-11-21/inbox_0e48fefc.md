## Grafana 13.3 Adds Shared Dashboard Variables and Notebooks

Grafana 新版讓多個儀表板共用變數，並加入記錄調查過程的筆記本。

**What** Grafana 13.3 新增跨 dashboard 的 shared variables，以及用來記錄調查過程的 Notebooks。兩者都是 public preview，自行架設的環境需要開啟 feature toggle 才能使用。

### 重點
- Grafana 13.3 新增跨 dashboard 共用的 shared variables
- 新增 Notebooks，用來記錄調查（investigation）過程
- 兩項功能皆為 public preview，self-managed 需啟用 feature toggle

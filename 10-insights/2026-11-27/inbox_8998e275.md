## Meta Brings Code Review Auto-Approval More Mainstream with PyTorch GreenLight

讓 AI 審查者替低風險的程式碼變更直接核准，只把高風險改動留給人看。

**Why** 程式碼審查成為瓶頸，低風險變更仍佔用維護者時間。

**How** 參照 Meta 的 RADAR：先經安全檢查，再算風險分數並做 LLM review，低風險 diff 自動合併。

**What** PyTorch 推出開源的 GreenLight，讓 AI 審查者能核准維護者自己提出的 pull request。原文指出 OpenAI、Anthropic 與 Sonar 也有類似的自動核准作法，同時對高風險變更保留人工審查。

### 重點
- PyTorch GreenLight 是 Meta RADAR 的開源版本，AI 審查者可核准維護者自己的 PR
- RADAR 流程：安全檢查 → 風險分數 → LLM review，通過者自動 land 低風險 diff
- OpenAI、Anthropic、Sonar 有類似自動核准機制，高風險變更仍由人審查

PyTorch now lets an AI reviewer approve pull requests from its own maintainers. GreenLight is an open-source take on RADAR, the system Meta uses to auto-land low-risk diffs after safety checks, a risk score and an LLM review. OpenAI, Anthropic and Sonar describe similar ways to automate approval while keeping humans on risky changes. By Andrew Hoblitzell

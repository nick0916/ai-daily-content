## 40x More Merged PRs With 2.7x the Engineers — Walden Yan, Cognition

Cognition 把整個開發流程交給 AI agent 自動跑，工程師改成給目標而非給任務，一年內合併 PR 數成長 40 倍。

**Why** 光買一個 coding agent 不夠，只要工作能被描述就能丟給 agent，工程師必須改變角色與基礎設施才能放大產出。

**How** 把團隊拆成 2–3 人小 pod 並擔負 QA 與 PM 的垂直責任；所有服務可用 Docker Compose 與 mock 在單一 VM 本地執行，VM 每小時重建；從 Slack 提 bug、由 Devin 回傳影片作為證據；並讓 agent 持續對可量測指標（如 P99 延遲、吞吐）做長時間最佳化。

**What** 一年內合併 PR 增加 40 倍，工程師人數只增 2.7 倍；講者自稱品質不低於以往（此為講者說法）。範例包括：以約一週讓 agent 調校 Vera Rubin GPU 推論吞吐，超越前代 GB300；以一個高階提示讓 Devin 花 44 天、每日合併 40–50 個 PR，依 iOS App 逐像素對照做出 Android App。

### 重點
- 一年內合併 PR 成長 40 倍、工程師人數成長 2.7 倍；小 pod（2–3 人）擁有 QA、PM 與客戶 bug 回報的垂直責任
- 基礎設施：所有服務以 Docker Compose 與 mock 在單一 VM 本地執行、VM 每小時以最新程式碼重建，build 失敗由 Devin 先行修復，測試技能由 agent 自行維護
- 從給任務改為給「工作目標」：把可量測指標（P99 延遲、吞吐、layout shift）交給 agent 長期最佳化；Android App 案例用單一高階提示加持續 hooks，44 天完成

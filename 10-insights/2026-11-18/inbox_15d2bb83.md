## The PSF end-of-year fundraiser

Python 軟體基金會（PSF）開始年終募款，呼籲受益於 Python 的公司與個人捐款。

**Why** PSF 是支撐 Python 開發與社群的非營利組織，靠捐款維持營運。

**How** 資金用於維護 Python 智慧財產、營運 PyPI、贊助核心開發者 sprint、支援社群活動（含每年的 PyCon US），並聘用小型專職團隊。

**What** Simon Willison 以 PSF 董事身分宣布年終募款；PSF 的 Developers in Residence 計畫現有三位資安開發者（新加入 Brett Smith），專注強化 Python、PyPI 與整體生態系的安全。

### 重點
- PSF 負責 Python 智慧財產、PyPI 營運、核心開發者 sprint 與 PyCon US
- Developers in Residence 計畫現有三位資安開發者，新加入 Brett Smith
- Simon Willison 以 PSF 董事身分呼籲受益企業捐款

The PSF end-of-year fundraiser 
With my Python Software Foundation board director hat on: we've launched our end-of-year fundraiser for the non-profit that supports Python development and the Python community. 
 If your company or your work benefits from Python, please consider donating this year! 
 The PSF looks after the IP behind Python, operates PyPI, sponsors core developer sprints, supports community events (including running PyCon US every year), and employs a small and excellent staff team to keep everything running. 
 We also operate the Developers in Residence program , which now includes three security developers (welcome, Brett Smith) focused on helping secure Python, PyPI, and the wider ecosystem.

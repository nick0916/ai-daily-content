## Vercel Releases UI SDK for Agents to Compose UI from Reusable Behaviors

Vercel 推出一組可重用的 UI 行為函式庫，讓 AI agent 能組合並操作介面元件。

**Why** 讓 agent 能組出符合無障礙標準的元件，並能透過明確的介面去操作它們。

**How** 以 @ui-sdk/core 提供超過 50 種 UI 行為，搭配 React、Vue、Svelte、Solid 與 Web Components 的 adapter，並提供有文件說明的 agent bridge 讓 agent 操作元件。

**What** Vercel UI SDK 進入 beta，採 Apache 2.0 授權、TypeScript 撰寫。

### 重點
- @ui-sdk/core 含 50+ 種 UI 行為，Apache 2.0、TypeScript
- 提供 React、Vue、Svelte、Solid、Web Components adapter
- 透過有文件的 agent bridge 讓 agent 組合並操作無障礙元件

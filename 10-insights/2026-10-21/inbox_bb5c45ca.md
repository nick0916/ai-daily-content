## Microsoft Previews dotnetup: Toolchain Manager for .NET SDKs and Runtimes

微軟推出一個工具，讓你不用管理員權限就能安裝與更新 .NET。 **What** Microsoft 發布 dotnetup 公開預覽版，跨平台的 toolchain manager，將 .NET SDK 與 runtime 安裝在使用者自己的目錄；追蹤 latest、lts、preview、daily 等 channel，讀取 global.json，並可移除不用的安裝。指令在正式發布前仍可能變動。

### 重點
- 免 admin 權限、安裝於使用者目錄
- 支援 latest、lts、preview、daily channel，並讀取 global.json
- 可清除未使用的安裝；指令 GA 前可能變動

Microsoft has released a public preview of dotnetup, a cross-platform toolchain manager that installs and updates .NET SDKs and runtimes in the user’s own directory without admin rights. It tracks channels such as latest, lts, preview, and daily, reads global.json, and removes unused installs. Commands may still change before general availability. By Almir Vuk

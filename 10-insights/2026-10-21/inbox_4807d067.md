## rc/ab0b03846da74f1b17ff245246570febfe743559: fix(go): type receivers through package-qualified declared types (#3651)

修正 Go 接收者型別解析，保留套件限定名（如 *models.User）以避免同名型別錯綁。

**Why** 原本 normalizeGoTypeName 會去掉套件限定詞，兩個套件都宣告 User 時會找錯或找不到型別。

**How** 新增可選的 ScopeResolver.qualifiedTypeLookupSpelling hook，依 import 還原 models.User 的寫法優先查找，失敗才退回原本的 bare lookup。

**What** 與 main 的 A/B 比對中，新增 19 條 Go 邊、清除 13 條原被丟棄的 Go 邊，且除新 fixture 外沒有其他邊被移除或改指向；receiver benchmark 的 call drop 數從 153 降到 148，全部 kind 從 221 降到 208。

### 重點
- normalizeGoTypeName 去除套件限定詞，導致 *models.User 與 *vault.Vault 等同名型別無法正確綁定
- 新增可選的 ScopeResolver.qualifiedTypeLookupSpelling hook，優先依 import 還原限定名，失敗時退回 bare lookup
- A/B 比對：新增 19 條 Go 邊、清除 13 條 Go drop；receiver bench call drop 153→148、全部 kind 221→208

normalizeGoTypeName cuts the package qualifier from field, parameter and 
local types, so *models.User is stored as User and the bare lookup either 
refuses the name or binds the wrong package once two packages declare a 
 User . A new optional ScopeResolver.qualifiedTypeLookupSpelling hook 
recovers models.User from the written spelling; receiver typing (compound 
receivers, simple bindings and callable-value-flow method values) tries it 
first, grounded on the qualifier's import with the unique-name fallback off, 
and falls back to the bare lookup on any miss. The qualifier is read from the 
module scope so vault *vault.Vault cannot shadow its import, and a chain 
step keeps a binding's own written spelling so a binding whose type the step 
replaced never borrows another binding's package. 
 Corpus A/B against main: no edge removed or retargeted outside the new 
fixture; 19 Go edges added and 13 Go drops cleared. Receiver bench: call drops 
153 -&gt; 148, all kinds 221 -&gt; 208.

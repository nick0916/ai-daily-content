## v2.1.306

Claude Code 的小修補版，修好雲端 session 內 `claude -p` 的登入判斷與 MCP 工具過多時的錯誤訊息。 **What** Claude Code v2.1.306 修正兩個問題：在雲端 session 內未帶 session 環境變數啟動 `claude -p` 時誤報 "Not logged in"；以及在 MCP 工具很多的 session 中，API 錯誤被誤替換成 "prompt is too long" 並觸發不必要的壓縮。

### 重點
- 修正雲端 session 內 `claude -p` 在未帶 session 環境變數時誤報 "Not logged in"
- 修正 MCP 工具很多時，API 錯誤被誤顯示為 "prompt is too long" 並引發不必要的 compaction

## eMudhra Intermediate CA Compromise

一家憑證機構的八把中繼 CA 私鑰外洩，內建信任清單的軟體都得更新。 **Why** 這些中繼 CA 憑證鏈到 Mozilla、Microsoft、Apple、Chrome 信任的根憑證，私鑰外洩代表攻擊者可簽發被瀏覽器與系統信任的憑證。 **What** Simon Willison 轉述：eMudhra 的八個中繼 CA 憑證私鑰已遭入侵，任何內建信任憑證清單的軟體都需更新，Linux 發行版要更新 ca-certificates 套件。Python 生態已釋出 uv 0.13.4、pip 26.2.2、certifi 2026.10.19，內含更新後的憑證清單。

### 重點
- eMudhra 八個中繼 CA 憑證私鑰外洩，鏈到 Mozilla、Microsoft、Apple、Chrome 信任的根憑證
- Linux 發行版需更新 ca-certificates 套件，有專門網站與 GitHub repo 追蹤各軟體更新進度
- Python 端修補版本：uv 0.13.4、pip 26.2.2、certifi 2026.10.19

# eMudhra Intermediate CA Compromise

eMudhra Intermediate CA Compromise 
This is very, very bad news: 
 
 The private keys of eight eMudhra intermediate CA certificates have been compromised. They chain to roots trusted by the Mozilla, Microsoft, Apple and Chrome root programs and by many downstream trust stores. 
 
 Any software that bundles a list of trusted certificates needs to be updated. This site is tracking software updates via this GitHub repository - Linux distros need to update their ca-certificates packages. 
 In Python world uv 0.13.4 and pip 26.2.2 and certifi 2026.10.19 have been released with upgraded certificate lists.

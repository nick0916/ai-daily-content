## Instagram Modernized its UI with an AI-Native Architecture, Cutting Token Costs by 33%

Instagram Direct 把 Android UI 從舊有的 Android View 系統遷移到 Jetpack Compose，目標是打造一個更容易讓 AI coding agent 理解、修改與維護的「AI-native」UI 程式碼庫。依 Instagram 工程師的說法，遷移後 UI 程式碼量減少 50%。每次 AI agent session 的 token 成本降低 33%。這個案例顯示，程式碼庫本身的結構與簡潔度會直接影響 agent 的運作成本。對有大型舊程式碼庫的團隊而言，可把重構為宣告式框架視為降低 agent 成本的手段之一。原文摘要未說明這 33% 的量測方法或樣本範圍。

### 重點
- Instagram Direct 的 Android UI 從 Android View 遷移到 Jetpack Compose
- UI 程式碼量減少 50%
- 每次 AI agent session 的 token 成本降低 33%

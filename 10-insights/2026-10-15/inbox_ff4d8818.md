## Is Meta’s Muse Wonder model any good?

主持人以自己的 How I AI benchmark 初測 Meta 的 Muse Wonder：agent 與語氣表現強，設計與創意任務明顯落後。

**Why** Meta 宣稱 Muse Wonder 在個人與專業 agentic 工作達到 frontier 水準，主持人想驗證能否用在自己的 agent 與寫程式流程。

**How** 她透過 Muse Code 以 Claude Code 無頭模式呼叫模型，跑近 20 項任務（原型、agentic、寫程式、寫作、創意），由 LLM 評分後再由她語音評分。

**What** Muse Wonder（含 Wonder 與 Wonderful 兩版）在 agentic 任務最佳：計費工單處理、inbox triage、電腦操作、email 與助理語氣都排第一，且能抵禦 prompt injection；後端寫程式屬同級水準；但前端設計約落後 12–18 個月，chat PRD 網站重做效果差，SVG 為 8 個模型中的第 7，短影片剪輯只給 2 分。單次短任務很快，長任務較慢。

### 重點
- agentic 任務最佳：計費工單測試（連錯帳號、重複退款、prompt injection）全部處理正確，inbox triage、電腦操作、email、助理語氣皆排第一
- 弱項：前端設計（圓角襯線字體、互動壞掉、dark mode 要求被忽略）、PRD 過短、SVG 8 個模型中排第 7、短影片剪輯 2/5，創意與設計仍偏好 Opus 5.5
- 主要宣稱的能力：domain expertise、active memory、active focus（持續投入），主持人在長任務上確實看到 active focus 的優勢；單次短任務快，長任務耗時較久

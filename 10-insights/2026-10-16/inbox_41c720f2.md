## Google EnvHarness Enables Self-Evolving Agents to Learn in Dynamics Environments

Google 研究人員開源 EnvHarness，這是一個能根據 agent 的弱點動態調整訓練環境的框架。其特點是不需修改 agent、環境本身或評估系統。研究人員表示，此做法可同時提升學習效果與效率，並幫助 agent 克服弱點。核心概念是讓「環境」而非 agent 來適應，以支援 self-evolving agents 在動態環境中學習。對 agent 訓練與 RL 研究者而言，這提供一種不動既有 agent 與評估流程的整合方式。原文摘要未提供具體的 benchmark 數字。

## Helidon 27 Introduces Restructured Programming Models and New Messaging and Data Modules

Helidon 27 發布，是首個遵循 Oracle「Tip & Tail」函式庫開發模型的版本：Tip 採用最新 Java 技術，Tail 則提供較穩定且安全的基線。此版本與 JDK 27 同步推出，新增主要模組 Helidon Messaging 與 Helidon Data JDBC，標題並提到程式設計模型經過重組。原文摘要未說明重組的細節或其他版本數字。影響對象為使用 Helidon 的 Java 微服務開發者，需評估要跟隨 Tip 或維持在 Tail 基線。

### 重點
- Helidon 27 為首個採用 Oracle Tip & Tail 模型的版本
- 與 JDK 27 同步發布
- 新增 Helidon Messaging 與 Helidon Data JDBC 兩個主要模組

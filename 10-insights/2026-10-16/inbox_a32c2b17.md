## AI in Production: Panellists Highlight Silent Failures, Harness Engineering, and Agent Governance

InfoQ 舉辦網路研討會，探討部署 agentic 系統進入 production 時的營運挑戰。講者指出 semantic drift 與 embedding drift 是隱性失敗（silent failures）的來源，可能在沒有明顯錯誤訊號的情況下造成重大錯誤。與會專家也談到需要自動化 code review、對模型持續進行評估（continuous evaluation）、強化隱私保護措施，並強調部署與資安管理應採策略性作法。標題另提到 harness engineering 與 agent governance，但原文摘要未說明具體做法。本文僅為研討會簡短報導（作者 Olimpiu Pop），沒有給出量化數據或具體工具。對正在把 agent 推上線的工程團隊而言，重點是把 drift 監測與持續評估納入維運流程。

### 重點
- semantic drift 與 embedding drift 會造成隱性失敗，可能導致重大錯誤
- 建議實務：自動化 code review、模型持續評估、加強隱私措施

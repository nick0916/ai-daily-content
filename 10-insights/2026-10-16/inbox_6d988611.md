## v0.57.0

Repowise v0.57.0 是一次大型累積更新，絕大多數為修正，集中在多語言程式碼圖譜（graph）解析、health 分析與 MCP 工具。圖譜方面：改善 Java（overload 選擇、call chain 型別、@interface、匿名類別各自成節點、Spring 路由連到 handler 方法）、Kotlin（alias import、建構子屬性、extension 綁定）、Swift、Dart 的 receiver 型別推斷；tree-sitter-swift 升至 0.7.4。Health 方面：Fix first 依函式自身變更歷史排序、新增 Swift complexity map、針對 Java 迴圈中的 Spring Data／MyBatis 呼叫提出警示、多數程式碼未被分析時不顯示 headline band。Refactoring 為 Go、Rust、JVM、Ruby 計畫加入測試指令，並支援以 dotnet test 執行 C# 測試。MCP 與 dead-code 也有多項修正（如 get_change_risk 找不到 git 時明確提示、Gradle/Android entry roots、Compose previews 與 Dagger/Hilt modules 視為框架載入）。注意原文在中途被截斷，後續變更未列出。

### 重點
- Java／Kotlin／Swift／Dart 圖譜解析大量修正，並新增 Spring routes 連結 handler 方法（#3650）與 tree-sitter-swift 0.7.4（#3647）
- Refactoring 為 Go、Rust、JVM、Ruby 計畫加入測試指令（#3585），C# 以 dotnet test 執行（#3583）
- Health：新增 Swift complexity map（#3450）、Fix first 依函式變更歷史排序（#3565）、多數程式碼未分析時不顯示 headline band（#3641）

## Chainguard Launches Secure Workspaces and Checks for AI Coding Agents

軟體供應鏈安全公司 Chainguard 在倫敦的 Assemble 活動上宣布兩項 beta 產品，用於執行與測試開發者及 AI agent 撰寫的程式碼。Chainguard Workspaces 提供以強化版 microVM 為基礎的遠端開發環境。Chainguard Checks 則把持續整合（CI）移進開發迴圈之中。這兩項產品的定位是為 AI coding agent 產生的程式碼提供較安全的執行與驗證環境。目前兩者都處於 beta 階段。原文摘要未提供價格、支援的 agent 或效能數據，實際能力需待後續資料確認。

### 重點
- Chainguard Workspaces（beta）：以強化版 microVM 為基礎的遠端開發環境
- Chainguard Checks（beta）：把 CI 移入開發迴圈
- 對象為開發者與 AI agent 所寫的程式碼，於 Assemble London 發表

Software supply chain security company Chainguard has announced two beta products for running and testing code written by developers and AI agents.

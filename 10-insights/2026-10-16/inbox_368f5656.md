## dev-1.0.2-rc.550

RTK（rtk-ai/rtk）發布 dev-1.0.2-rc.550 預發布版本，內容為合併 PR #4578（分支 fix/git-log-usage-exit-zero）。修正為「fix(git): no log cap notice under git's usage on git 2.56」，即在 git 2.56 顯示 usage 時，不再輸出 log 上限提示。原文僅有這一行，未提供更多背景。

### 重點
- dev-1.0.2-rc.550 合併 PR #4578
- 針對 git 2.56 的 usage 輸出，不再附加 log cap 提示

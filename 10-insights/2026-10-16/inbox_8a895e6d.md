## Zod Brings In-Process Schema Compilation and a 9x Cut in Memory Footprint

TypeScript 導向的 schema 驗證函式庫 Zod 近期發布 4.5 與 4.6 版。主要更新包括：以 schema compilation 加速資料解析、大幅降低記憶體用量（標題指出記憶體 footprint 減少 9 倍），以及新增驗證功能。Zod 在 JavaScript 生態系中仍相當受歡迎，每週下載量達數百萬次。對使用 Zod 做 API 或 LLM 結構化輸出驗證的 TypeScript 開發者，升級可能帶來效能與記憶體上的好處。原文摘要未提供解析速度的具體倍數與新驗證功能的細節。

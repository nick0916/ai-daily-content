## AWS Introduces Strands Decider 2B and Strands Box for AI Agent Development

AWS 推出兩個開源專案用於 AI agent 開發：Strands Decider 2B 與 Strands Box。Strands Decider 2B 是一個小型模型，設計用於在 agent 工作流程中做決策；Strands Box 則是用來控制 agent 執行的沙箱（sandbox）。兩者分別處理建構 agent 的不同面向，即使用工具、執行程式碼以及與外部系統互動。從名稱可知 Decider 為 2B 規模，但原文摘要未說明架構、benchmark 或授權細節。對開發 agent 的團隊而言，這提供了以小模型負責路由決策、並以沙箱限制執行風險的組合選項。

### 重點
- Strands Decider 2B：小型模型，用於 agent 工作流程中的決策
- Strands Box：控制 agent 執行的沙箱
- 兩者皆為開源，分別對應決策與執行安全

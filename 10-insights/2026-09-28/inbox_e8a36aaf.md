## 想用 AI 打造系統?別讓「部署上線」成為你的最大阻礙!

讓 Claude 直接操作你已登入的瀏覽器，把專案一路部署到雲端。

**Why** 用 AI 做出系統已不難，真正卡住非工程師的是部署：教學步驟會隨服務介面改版而過時，自己照做常中途卡關。

**How** 先裝 Claude 電腦版與 Chrome 擴充套件，在瀏覽器登入 Netlify、Supabase，於 Claude Code 切到 Bypass 權限模式，貼上 GitHub 專案連結，請它依 README 部署，過程中需輸入的資料都自行設定，最後回報登入資訊。

**What** 講者用開源 AI 客服系統（Supabase + Netlify）示範，Claude 自動建專案、貼 SQL 執行、部署，最後列出後台網址、管理員帳密與專案資訊。使用 Claude Code 需付費方案，講者稱每月 20 美元；他也提到可用同樣方式在 Google Cloud 建 VM 部署，或請它協助購買網域，並建議讓它先選最便宜方案、有選項時先問你。

### 重點
- 流程：Claude 電腦版 + Chrome 擴充套件 → 瀏覽器先登入目標服務 → Claude Code 的 Bypass 權限模式（需在 Settings 的 Claude Code 分頁先允許）→ 貼 GitHub 連結並請它讀 README 部署
- Prompt 技巧：說明已登入哪些服務、部署步驟看 README、輸入欄位自己設定不要問、最後回報設定的登入資訊
- 也可用於 Google Cloud VM 部署：先登入並完成驗證，請它選便宜方案、有選擇時先詢問；Bypass 模式會省去逐步授權，但代表信任 AI 自動操作

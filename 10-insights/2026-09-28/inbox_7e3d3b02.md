## Can't Backup Large iCloud Files? Let AI Help You Get It Done!

請 AI 代你在終端機裝好開源工具，把 iCloud 照片影片完整備份下來。

**Why** iCloud 容量大時，Apple 官網的匯出功能容易下載失敗、解壓縮失敗或缺檔，影片認為一兩百 GB 以內還可行。

**How** 在 ChatGPT 或 Claude 電腦版建立專案、指定備份資料夾，用 prompt 請 AI 安裝 GitHub 上的 iCloud Photos Downloader 並執行；AI 不代輸入帳密，只有 Apple ID 登入與兩階段驗證由使用者自己完成。

**What** 影片示範 ChatGPT 電腦版，並說明 Claude 也可用；之後對同一資料夾再執行會增量備份，只補下載沒備份過的檔案。講者也提到這個做法可延伸到手機上其他備份或轉移問題。

### 重點
- 工具是 GitHub 開源免費的 iCloud Photos Downloader，講者實測以終端機安裝比桌面執行檔穩定
- Prompt 要點：指定 GitHub 來源（或直接給網址）、說明要備份 iCloud 照片影片、登入與驗證自己處理；選完整存取權可減少中途詢問
- 對同一資料夾重複執行為增量備份，只下載新增檔案，不會全部重抓

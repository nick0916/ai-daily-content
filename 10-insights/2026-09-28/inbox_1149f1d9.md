## Muse gets AI agent UX right

Meta 推出給家長用的個人 AI agent Muse，作者認為它的產品設計比多數 agent 都好。

**Why** 多數 agent 偏工程師與工作場景，一般消費者面對 VM、權限與錯誤訊息會困惑也缺乏信任。

**How** 介面只露出瀏覽器而非整台 VM、在關鍵步驟逐步請求授權（不用 YOLO 或每次詢問模式）、用 activity feed 記錄每個 tool call，並以 Feed、Ideas、Goals、Library 等消費者用語取代 cron、to-do、artifact。

**What** Muse 由 Meta 推出，內建 identity／soul／memory 可手動編輯（有 OpenClaw 影子），可透過 WhatsApp 使用，付款走 Stripe Link、支援 1Password。作者實測：一次產出品質高的一頁家庭晨報 PDF、約 6 分鐘的 podcast、gentle sleep training 目標追蹤，但買鞋時 browser use 失敗，買電影票則較成功。

### 重點
- Muse 的新 primitive：Feed（個人化資訊流）、Ideas（/ideas 建議任務）、Goals（個人目標加提醒，非 to-do）、Library（成果庫，含 PDF、網站、圖片、影片、podcast）
- 設計手法：只露出瀏覽器而非整台 Linux VM；逐步請求授權（先問能否讀 email，再問能否使用所得資訊）；activity feed 呈現每個 tool call 的 lineage
- 實測弱點：購物 browser use 找錯配色且卡住（New Balance 960），查電影票流程較順；作者認為 Muse 勝在設計而非模型最強

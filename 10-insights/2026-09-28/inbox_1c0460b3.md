## Who Owns Your Data Now? Agents vs. Systems of Record on The Agents #013

當 AI agent 開始寫入並掌握客戶資料，傳統 system of record（CRM 等）的護城河與成本結構都會被重新檢視。

**Why** Agent 產生的資料量遠超過去，而 system of record 的儲存與 API 存取成本高昂；廠商若提高 API 費用，只會促使客戶把資料搬出去。

**How** 主持人以自家 headless Salesforce 為例：由 10K 代理串接 Salesforce、Qualified、Momentum、Agentforce 等；並自建 renewal agent，結合 Salesforce、社群、Podcast、Gmail 資料，經 Gamma API 產生客製續約簡報，且先與人類確認「narrative」才產出。

**What** 本週 ServiceTitan 以 30 天通知切斷 Podium 的整合，因 Podium 的 agent 開始侵蝕其 system of record 地位。Salesforce 資料已約 40GB、約 2,100 萬筆紀錄，Claude 估算搬到 Postgres 約便宜千倍（主持人表示未驗證準確性）。Renewal agent 讓連最小的 silver 贊助商也拿到與大客戶同等品質的客製簡報。

### 重點
- ServiceTitan 給 Podium 30 天通知後切斷整合：Podium 的 agent 已能互動客戶、排程並成為 system of record
- Salesforce 資料約 40GB、約 2,100 萬筆；Claude 估算搬到 Postgres 約便宜 1000 倍（主持人自述未必準確），平台若調高 API 價格會促使資料外移
- Renewal agent 技巧：先由 agent 提出 narrative 並與人確認再生成簡報，使所有層級贊助商都獲得同品質客製內容

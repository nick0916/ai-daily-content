## Claude is BACK with Opus 5.5

Anthropic 發布 Claude Opus 5.5，主持人實測後認為它終於「不煩人」，前端設計與長任務表現出色，Claude 重回她的工作流程。

**Why** 她先前因 Fable 與 Opus 5 太冗長、難溝通而放棄 Claude，改用 Codex；模型好不好用，除了智慧也取決於溝通風格。

**How** 以 PRD、原型、程式碼審查、長任務 agent、收件匣整理、computer use、SVG 等實際工作測試，並與 GPT 模型交叉審查 PR。

**What** 官方宣稱接近 Fable 5.1 的表現，但比 Opus 5 便宜約 40%、快約 30%；定價 $4 / $20（fast mode $8 / $40），思考恆開、預設中等 effort。測得的長任務 25–82 步皆成功，並能忽略 prompt injection。前端與 SVG 插圖表現最好，但仍偏保守會說「不」、安靜不報進度讓人感覺較慢，且仍偏好 Codex 的 harness。首度搭載 Fable 級資安與生物防護，相關任務會被降級至 Opus 4.8。

### 重點
- 規格價格：比 Opus 5 便宜約 40%、快約 30%；$4/$20 每百萬 token，fast mode $8/$40；思考恆開、預設中等 effort
- 長任務測試 25–82 步皆成功：忽略 prompt injection、修正 computer use 中錯誤歸屬的工單、發現 44 張 Confluence 票中 41 張來自同一客戶
- 缺點：偏保守會拒絕 yolo push、為了不煩人而長時間不報進度，使速度感較慢；她仍把 computer use 與影片剪輯留給 Codex

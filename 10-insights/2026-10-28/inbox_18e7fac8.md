## AI That Hunts Logic Bugs Before Attackers Do - Taylor Luttrell-Williams, Sonar

用 AI agent 去找傳統靜態掃描抓不到的「邏輯與意圖」漏洞。

**Why** 傳統 SAST 擅長比對程式碼模式，但無法處理程式碼語法正確、卻違背商業邏輯的漏洞；而 agent 產出程式的速度與量都在增加，滲透測試最多一年一兩次。

**How** 先由一個 agent 建立整個 repo 的全域地圖，再啟動三個專責 agent 分別處理一類問題，之後做對抗式驗證排除誤報，並以 noise gate 濾掉低價值或屬於設計本意的結果。

**What** SonarQube Hunter Agent 針對三類漏洞：broken access control、business logic、authentication／session。Demo 在一個 Python 專案掃出 46 個問題，耗時約一小時，結果與一般 SonarQube issue 同列，並可排程掃描；問題可指派給 SonarQube remediation agent 自動修復。Sonar 並宣布加入 OpenAI Daybreak Cyber Partner Program，以取得資安前沿模型。

### 重點
- 架構：全域 repo 地圖 → 三個專責 agent（broken access control／business logic／auth & session）→ 對抗式驗證 → noise gate
- Demo：一個 Python 專案掃描約 1 小時、46 個 open issues；可排程（每日／每週／每月）、可指定分支，支援 SonarQube Cloud 與 Server
- Sonar 加入 OpenAI Daybreak Cyber Partner Program；本週起問題可指派給 remediation agent 自動修復

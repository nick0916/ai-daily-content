## Grok vs. Dot vs. Muse vs. Claude Duet: which one crushes the competition?

用同一組 9 項日常任務實測四個個人 agent，結論是依任務挑 agent，沒有通吃的贏家。

**Why** 作者同時使用多個 agent、各自連接的工具不同，想用統一基準看清楚哪個 agent 適合哪類工作。

**How** 從各 agent 回報的常用任務挑出 9 項，用一句話口語 prompt 執行並計時；由 Claude 與 Codex 以 computer use 操作各 agent，並先確認連接器與 skills 大致一致；評分是講者現場主觀判斷，非盲測。

**What** 比較 Dot、Grockbot、Muse、Claude Duet。依講者與 Claude 的總評，Grockbot 勝出（完成率 93%），在縮圖（Figma）、待辦整理、購物勝出；Muse 擅長創意與個人任務（短影片、家庭報紙、作業講解，且最快）但缺少商務工具；Dot 偏後；Claude Duet 最後（79%），影片剪輯失敗，但在修 bug 與產品發布影片表現最好。

### 重點
- 結果摘要：Grockbot 93% 總評最高；Muse 在 9 項中 4 項最快但因缺 Slack/GitHub 只完成 7 項；Claude Duet 同樣只完成 7 項（影片剪輯失敗、家庭報紙僅輸出 markdown）且總評 79%
- 各任務贏家：修 bug 為 Dot 最接近正解，Claude Duet 另找到第二個 bug，Grockbot 以放寬驗證了事最差；縮圖、待辦、購物為 Grockbot；短影片、家庭報紙、作業講解為 Muse；產品發布影片為 Claude Duet
- 方法心得：測試前先用 browser use 確認各 agent 連接器與 skills 一致；Claude 的權限詢問次數為 4 次、其他為 1 次；講者結論是工作任務偏向 Grockbot、生活任務偏向 Muse，寫程式仍建議直接用 Codex 或 Claude 本身

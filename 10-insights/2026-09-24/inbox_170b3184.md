## v0.53.0

Repowise v0.53.0 發布，release 標題為「Laravel、NestJS、Node 與 Angular contracts，以及只宣稱自己能證明之事的 performance plans」。主要新增：workspace 能讀取 Laravel 路由（含 group）、migration 轉為 table、queues/pub-sub/socket events（#2512、#2525），NestJS routes、Node HTTP clients 與 Node ORM tables（#2527），Angular HttpClient 呼叫與 app entry points（#2531）。performance 方面新增 over-fetch detector（#2495）、對 lazy-loaded relationship 在 loop 中逐列讀取的偵測（#2528），並讓 plans 只在事實能證明前提時才被 promote（#2504）。安全面：偵測 vendor credential 格式與 PEM keys（#2223），並遮罩所有已儲存 snippet 中的 secrets（#2496）。另有 UI 改善（contracts/co-changing file pairs 以 drawer 呈現）與多項社群貢獻修正，新增 2 位 contributor（@8rulerstar、@Tyagiquamar）。

### 重點
- workspace 新增 Laravel、NestJS、Angular HttpClient 與 Node ORM 的 contract 解析（#2512、#2525、#2527、#2531）
- performance plans 改為只在事實能證明時才 promote（#2504），並新增 over-fetch 與 lazy relationship in-loop 偵測（#2495、#2528）
- 安全：偵測 vendor credential 與 PEM key（#2223），並遮罩所有已存 snippet 中的 secrets（#2496）

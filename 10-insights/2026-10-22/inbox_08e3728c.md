## Vercel Labs Open-Sources fx: A Zig Coding Agent Designed to Be Embedded

Vercel Labs 開源一個用 Zig 寫的小型 coding agent，可以嵌入到其他程式裡使用。 **What** Vercel Labs 釋出實驗性開源專案 fx，可作為 CLI、script component 或嵌入式 library，並提供 WebAssembly build。早期回饋質疑其 model-agnostic 的說法，以及與既有工具的名稱衝突；Vercel 表示專案仍是 pre-1.0，變動快速。

### 重點
- fx 以 Zig 撰寫，形態包含 CLI、script component、embedded library，並有 WebAssembly build
- 早期回饋質疑 model-agnostic 宣稱，且名稱與既有工具衝突
- Vercel 表示專案為 pre-1.0、快速變動中

Vercel Labs has released fx, an experimental open-source coding agent written in Zig. It runs as a CLI, a script component, or an embedded library, including a WebAssembly build.

## Donating Agent Skills to the Agentic AI Foundation

Anthropic 把 Agent Skills 這份規格交給中立基金會管理，不再由單一公司掌控。 **Why** Anthropic 表示要讓 Agent Skills 保持開放、由社群驅動且不綁定特定廠商。 **How** 將標準捐贈給 Linux Foundation 旗下的 Agentic AI Foundation（AAIF）；該基金會由 Anthropic 與 Block、OpenAI 於去年共同創立，MCP 也已捐贈給它。 **What** Simon Willison 指出他去年 12 月 Anthropic 宣布 skills 為開放標準時就預測過此事。他也提到透過 datasette-mcp 外掛，Claude 能查到自己的部落格文章。

### 重點
- Agent Skills 標準捐贈給 Linux Foundation 旗下的 AAIF
- AAIF 由 Anthropic、Block、OpenAI 去年共同創立，MCP 已在其中
- Simon Willison 去年 12 月已預測 skills 會進入 AAIF

Donating Agent Skills to the Agentic AI Foundation 
News today from Anthropic: 
 
 We’re committed to keeping Agent Skills open, community-driven, and vendor-neutral. Today, we are donating the standard to the Agentic AI Foundation (AAIF) under the Linux Foundation, which we co-founded with Block and OpenAI last year, and to which we donated the Model Context Protocol (MCP). 
 
 I'm pleased to note I called this one last December , when Anthropic first declared skills to be an "open standard": 
 
 I wouldn't be surprised to see this end up in the AAIF , recently the new home of the MCP specification.

## Google Cloud API Gateway Introduces Streaming Support for Real-Time and AI-Powered Applications

Google Cloud 的 API Gateway 新增串流支援，讓它能處理需要即時雙向溝通的應用。

**Why** 原本的請求—回應模型不適合需要即時通訊的應用，Google 指出這對串流模型回應、多步驟 agent 工作流程與互動式 session 尤其重要。

**What** Google 宣布 API Gateway 的串流支援進入 public preview（InfoQ 報導，作者 Sergio De Simone）。內文僅為簡短摘要，未提供技術細節。

### 重點
- Google Cloud API Gateway 串流支援進入 public preview

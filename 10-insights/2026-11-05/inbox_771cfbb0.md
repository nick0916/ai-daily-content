## AI Labs Will Trap You or Replace You - Dillon Rolnick, Nous Research

主張模型已商品化，企業應把 agent 建在自己能掌控的開源基礎上，避免被實驗室綁住或取代。

**Why** 講者認為模型正在商品化，實驗室為回收巨額投資，只能往 agent 層綁定企業，或直接下場解決高價值問題如金融業。

**How** 以開源 agent（Hermes Agent）作為基礎，企業可自選與替換模型，並把確定性程式與非確定性判斷組合成新型應用，把護城河放在網路效應、聲譽與可靠度，而非專有 IP。

**What** Nous Research CEO Dillon Rolnick 的演講，推廣 Hermes Agent，稱其為全球下載量最多的開源 agent；並舉例他們用 Hermes Agent 在一個週末內重現了 XAI Grokbots 的介面。這是立場鮮明的倡議，其中對實驗室動機的判斷屬於講者個人推論。

### 重點
- 論點：模型 token 單價下降但總支出上升，實驗室將轉向 agent 層綁定企業或直接進入金融等高利潤領域（講者推論）
- 主張 agent 更像作業系統或框架，應結合確定性程式、資料來源與判斷力，並在自己擁有的基礎上可替換模型
- 舉例：用 Hermes Agent 一個週末重現 XAI Grokbots 並以開源功能釋出；講者認為護城河轉為網路效應、聲譽、可靠度

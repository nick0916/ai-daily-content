## How Netflix Evaluates AI When There's No Right Answer - Cameron Wolfe, Netflix

評估沒有標準答案的 AI 任務時，用「人工評估→離線自動評估→線上監控」三層流程，並在每一層用統計方法壓低雜訊。

**Why** 評估本來就有非確定性 agent 與小樣本的雜訊，主觀任務連 grader 也變成非確定性的 LLM judge，雜訊更大、結果更難信。

**How** 先與領域專家寫品質準則並讓多位評審對同資料校準一致性；用 power analysis 估算需要多少資料；再用 LLM judge 或 rubric 當自動代理，並以人工 golden data 做 meta evaluation；最後用 A/B test 與 production 指標驗證，並以 resampling、信賴區間等降低變異。

**What** Netflix 研究科學家 Cameron Wolfe 在 AI Engineer 的演講；rubric 為任務專屬檢查清單、LLM judge 則依通用品質準則，並舉 Netflix 例子：LLM judge 輸出與放棄率等串流指標有因果相關；judge 與人的一致度目標可參考人與人之間的一致度。

### 重點
- 三段式流程：人工評估作為北極星 → 離線 LLM judge/rubric 擴大實驗 → A/B test 與 production 監控，回頭補強前兩層
- 降噪手法：power analysis 估資料量、報告 error bar/信賴區間、對模型與 judge 做 resampling
- judge 的 meta evaluation：以人工 golden data 比對（相關性、二元準確率），一致度標準以人類評審間的一致度為基準；Netflix 例證 judge 判斷與放棄率有因果相關

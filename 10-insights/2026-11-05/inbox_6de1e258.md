## How We Took an AI Agent From 41% to 97% Accurate - Milind Sunil Shah, Brainbase Labs

把 AI agent 當成要反覆量測、修正的產品，從 41% 準確率一路調到 97%。

**Why** 後台作業 agent 只要一步出錯，試算表就會出現看似完成、實則錯誤的儲存格，因此需要可重複的方法持續提升準確度。

**How** 六步框架：kickoff 對齊勝利條件、ontology 明確定義每個詞彙、建立 benchmark 與 eval、先上線窄範圍的第一版 agent、反覆 score-fix-ship、最後交接整個迴圈。每次只改一件事，並且先改 instructions 再考慮換模型。

**What** Brainbase Labs 為 Domino's CMO 辦公室打造競品比價 agent：從 v1 到 v11，準確率 41%→97%，每個 source 成本 $2→$1，單次執行時間 129→71 分鐘，且全靠改 instructions、skills 與 playbooks。eval 混用程式碼檢查、LLM-as-judge 與 agent-as-judge；例如規則改成讀整頁而非只看被連結的區塊，並要求先讀 HTML DOM 與 alt text 再看圖片，使圖片讀取次數降為三分之一、成本降逾 50%。

### 重點
- 六步框架：kickoff → ontology → benchmarks → first agent → iterate → handoff；v1 的任務是被量測而非表現好
- Domino's 案例 v1→v11：準確率 41%→97%、$2→$1/source、129→71 分鐘，全靠 instructions/skills/playbooks 調整
- eval 三層：確定性程式碼檢查、LLM-as-judge 看 trace、agent-as-judge 逐一驗證被 flag 的價格；分析師修正後可直接轉成 benchmark case

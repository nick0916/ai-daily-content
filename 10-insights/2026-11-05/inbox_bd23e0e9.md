## Our Smaller Model Beat Opus on Finance Tasks - Alexander Shevchenko, Ramp

在等前沿模型進步的同時，用小模型、快取與大量平行 agent 先把成本與延遲壓下來。

**Why** 前沿模型雖然越來越便宜，但 Opus 4.6 這類模型在規劃與研讀大量試算表時仍慢且 thinking token 昂貴，Ramp 認為可在應用層再往下挖一層。

**How** 三種做法：與 Prime Intellect 後訓練 Qwen 3.5 35B 當金融問答模型，交給前沿 orchestrator 呼叫；用 cartridges 技術離線把大量脈絡壓進 KV cache；用 agentic map-reduce 讓上萬個平行 agent 掃描並去重驗證。

**What** Ramp Labs 後訓練的模型在該任務準確率超過 Opus 4.6 且延遲更低；以 10,000 個平行 agent 對 Ramp 做滲透測試，找到並修補 7 個高嚴重度漏洞，其中包含一個經由 email 觸發的 Lua script injection。另指出 open-weight 模型最多便宜 5 倍，在 swarm 設定下偵測率不會等比下降；並提到 Ramp 的 token spend management 與 Ramp Router 產品。

### 重點
- 後訓練 Qwen 3.5 35B（與 Prime Intellect 合作）在特定金融問答任務超越 Opus 4.6，並能以低延遲提供服務
- Cartridges 可將脈絡壓縮 20–30 倍進 KV cache，例如月結前一晚預先備好帳本與帳齡報表
- 10,000 平行 agent 滲透測試找到 7 個高嚴重度漏洞；便宜 5 倍的 open-weight 模型在 swarm 下偵測率不會等比降低

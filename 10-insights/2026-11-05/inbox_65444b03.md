## Presentation: Zero Trust Agent Systems that Pass Audits and Still Ship

把 AI agent 的安全防線從 prompt 移到工具層，既過稽核又不拖慢上線。

**Why** 生產環境中的 agent 面臨 prompt injection 等風險，但安全要求不能讓部署變慢或不合規。

**How** 把防禦邊界放在工具層、強制使用有範圍限制的 workload identity、處理經由工具輸出進來的 prompt injection，並設計可稽核的 observability 與 kill switch。

**What** Advait Patel 的演講提出保護生產環境 AI agent 系統的實戰手冊，目標是保護關鍵資料，同時維持快速且合規的部署。

### 重點
- 防禦邊界從 prompt 移到 tool layer
- 使用 scoped workload identities，並防範經工具輸出注入的 prompt injection
- 建立 audit-ready observability 與 kill switch

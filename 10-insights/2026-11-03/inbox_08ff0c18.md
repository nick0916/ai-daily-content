## Google Launches LiteRT Tensor API for Building, Customizing, and Optimizing ML Models for On-Device

Google 推出讓開發者直接在裝置上建構與優化機器學習模型的輕量 C++ 介面。

**What** Google 發布 LiteRT Tensor API，是一個輕量的 C++ API，讓開發者能為裝置端執行來建構、客製化與優化 ML 模型；官方表示它結合原生模型撰寫的彈性與跨平台可攜性。

### 重點
- LiteRT Tensor API 是輕量 C++ API，用於裝置端 ML 模型的建構、客製化與優化
- Google 稱其結合原生模型撰寫的彈性與跨平台可攜性

## You Can't Tell What's Real Anymore. Here's What Comes Next - Cristóbal Valenzuela, Runway

Runway 認為只要把「預測下一幀」放大做到即時，影片模型就能變成可互動的世界模擬器，甚至取代部分作業系統介面。

**Why** 影片本質是連續畫面的錯覺，模型為了預測下一幀必須學會物理、遮擋、物體恆存等現實規律；Runway 相信 scaling law 同樣適用於影片與世界模型。

**How** 讓影片模型即時生成並接受點擊等動作輸入（講者稱為 world interface model），沒有 Unity、Unreal、Blender 等 3D 表示；再把它接進 Continuum 原型，讓網頁內容變成可互動的「portal」，也能讓 coding agent 用它做視覺思考。

**What** 演講展示 Runway 的 Continuum 早期研究原型：可互動的即時影片 portal、依視窗大小改變的互動體驗、以及連接 coding agent 的 visual thinking。Runway 也成立機器人實驗室，並稱未來 8 到 12 個月內會陸續釋出大部分展示內容；講者說人類已分辨不出真假影片。

### 重點
- 核心論點：next-frame prediction 規模化後會湧現物理、重力、遮擋等理解，成為不需明確物理引擎的模擬系統
- Continuum 原型：即時影片模型作為作業系統介面，選取網頁內容即生成可互動 portal，並保留歷史作為「記憶」
- Visual thinking：把 Continuum 接到 coding agent，讓 agent 以視覺化方式思考問題，人也能據此更精準引導 agent

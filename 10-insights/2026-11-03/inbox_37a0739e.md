## datasette-agent 0.5a0

讓 AI 聊天視窗能貼在資料庫頁面旁邊，邊看邊改。

**Why** 單獨的聊天視窗與被修改的頁面分離，使用者難以對照結果即時迭代。

**How** 新增「panel」功能，讓 agent 聊天開啟並固定在 Datasette 的表格或查詢頁面旁；搭配 datasette-apps 可直接用 prompt 生成資料庫應用並在旁邊的聊天中持續修改。

**What** datasette-agent 0.5a0 發布，為重大版本；可用 GitHub 帳號登入 agent.datasette.io 試用。

### 重點
- datasette-agent 0.5a0 新增 panel：agent 聊天可固定在 Datasette 表格或查詢頁旁
- 搭配 datasette-apps 可 prompt 生成資料庫應用，並在旁邊聊天中修改
- 可用 GitHub 帳號登入 agent.datasette.io 試用

Release: datasette-agent 0.5a0 
 This is a significant release of Datasette Agent . The most notable new feature is called the panel - it lets the agent chat open and then sit next to pages from Datasette, for example a table or query page. 
 When combined with datasette-apps this means you can prompt a database-backed app into existence and then modify it from the chat that sits next to that app. 
 
 You can try it by signing in with your GitHub account to agent.datasette.io .

## We Built Grok Bot. Here Are Our 14 Best Bots | Peng Zheng & Lauren Tan

用一個 agent 負責拆解專案、調度其他 agent，讓團隊能同時跑大規模 agent 群。 **How** Lauren Tan 把大型專案交給 eng lead bot「Matcha」，Matcha 自己不做事，只拆解專案給其他 eng bot，每個 eng bot 再在雲端啟動 coding agent。 **What** Grok Bot 團隊（SpaceXAI）的設計師 Peng Zheng 透過 Figma MCP 讓設計 bot 依照描述檔案結構與設計系統的 skill，把他建立的一個關鍵畫面延伸到整個流程；Lauren 表示這讓她能跑「真正大規模的 agent swarm」。

### 重點
- Matcha 只負責拆解專案，不直接做工作，再由各 eng bot 在雲端執行 coding agent
- Peng 的設計 bot 經 Figma MCP 連接，並使用描述檔案結構、色彩、字型與間距的 skill
- Peng 的做法是「I will do the first 5%」：自己建立設計系統與一個 keyframe，其餘交給 bot 延伸到每個畫面

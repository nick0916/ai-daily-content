## Docker Urges Isolation and Governance for AI Agent Security

AI agent 能上網、跑程式、呼叫工具，所以光靠一般資安控制不夠，要把 agent 隔離並加上治理。

**Why** Docker 認為讓 agent 有用的自主性，同時讓傳統應用程式資安控制不足。

**How** Docker 主張以隔離（isolation）與治理（governance）作為主要防線，而不是只靠模型本身進步。

**What** Docker 發布指南，列出 agent 在人類監督有限時瀏覽、執行程式碼、呼叫工具所產生的五大資安風險；InfoQ 由 Matt Saunders 報導。提供內容未列出五項風險的具體名稱。

- Docker 的立場：主要防線是隔離與治理，而非單靠模型改進

Docker has published a guide to five security risks that arise when AI agents are allowed to browse, run code and call tools with limited human oversight. They argue that the autonomy that makes agents useful also makes conventional application security controls insufficient. The company positions isolation and governance, rather than model improvements alone, as the main defences. By Matt Saunders

## Why AI Makes You 100x Faster but Not Your Company - Mitchell Troyanovsky, Basis

個人用 AI 能快 100 倍，公司卻沒有，因為 agent 缺乏一致、由上而下的流程；解法是讓 agent 有『主見』並監督行為。

**Why** 組織靠流程讓非確定性的人產出穩定結果；但 coding 型 agent 把複雜度丟給使用者（能力落差），且做事方式由每個人自訂（流程落差），不符合公司擴張方式。

**How** 預先決定 agent 的做法（opinionated），用『behavior spec』寫下最重要的行為意圖，當作 rubric 去檢查沒有標準答案的軌跡；再配合 forking（在決策點分叉並詢問或改 context）與 simulations（請 coding agent 建立 sub-agent 模擬生產 agent）來迭代。

**What** Basis 為會計事務所打造 agent。講者建議把 agent 看到的 context 視為『runtime 訓練資料』；結果導向的 eval 難以擴展到數十萬情境，行為監督能取得更多訊號。信任度取決於『變更影響範圍』與『對對方能力的認知』兩軸，agent 需簡單且可靠才能擴散。

### 重點
- Behavior spec：只寫最重要的行為意圖，既對齊團隊，也當 rubric 檢查無 ground truth 的軌跡
- Forking：在失敗決策前一刻分叉，問 agent 為何如此或改 context 驗證；Simulations：請 coding agent 建立不得作弊的 sub-agent 模擬生產 agent，成本低、迭代快
- 把 context 視為 runtime 訓練資料，逐 token 在意；可靠與一致比完美重要

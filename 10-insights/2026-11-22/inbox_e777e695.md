## I Analysed 20,000 of My Claude Code Replies. 97% of the Tokens Were Claude Re-Reading Old Messages.

分析作者 65 億 token 的 Claude Code 對話，發現多數 token 花在重讀舊訊息。

**Why** 上下文視窗與用量上限被什麼吃掉，是使用者不易察覺的成本來源。

**How** 以作者自己的 session 紀錄統計各類內容的 token 佔用。

**What** 標題宣稱 2 萬則 Claude Code 回覆中約 97% 的 token 來自 Claude 重讀舊訊息；內文僅為預覽，未展開計算方式。

### 重點
- 分析對象是作者自己的 Claude Code 對話，共約 65 億 token（6.5B）
- 標題宣稱約 97% 的 token 是 Claude 重讀舊訊息，內文預覽未說明計算方式
- 預覽提到另有「九項內建」相關內容，但截斷未顯示，無法確認細節

## Presentation: RIIIR: Rewrite It In *Idiomatic* Rust (with AI)

用 AI 把程式改寫成道地的 Rust，並用標準協定讓 agent 接上各種工具。

**How** 以 Agent Client Protocol (ACP) 標準化 agent 與工具之間的擴充方式，適用於不同的企業開發流程。

**What** Nicholas (Niko) Matsakis 介紹 Rust Foundation 的開源 agent 導向工具鏈 Symposium，並示範 ACP 的用法。

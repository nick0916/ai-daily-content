## NVIDIA/SkillEvaluator ⭐ 3,919(今日 +312)

NVIDIA 開源的 agent skill 評估工具，檢查 skill 能否載入並量測其對任務結果的影響。

**Why** agent skill 修改後，品質與安全問題往往要到 merge 後才發現，需要在合併前攔截。

**How** 工具分三層：Tier 1 以 500+ 條靜態規則與多種掃描器做品質、安全與 Harness Check；Tier 2 做 skill 間去重與語意重疊偵測；Tier 3 實際執行 agent，比較有無 skill 的任務差異。

**What** 提供 GitHub 與 GitLab 的 CI 模板，可設定 quality 與 security gate；Tier 1 不需 API key，完整三層需 NVIDIA Build key 與 Docker；今日 GitHub 星數 3,919（+312）。

### 重點
- Tier 1 涵蓋 quality、schema、PII、license、Unicode、Harness Check，並整合 SkillSpector、Gitleaks、Bandit 等掃描器，`--tiers 1` 可免 API key 執行
- Tier 2 做去重與語意重疊偵測，Tier 3 在 sandbox 中實際執行 agent，衡量 skill 帶來的效果提升（skill lift）
- 提供 GitHub 與 GitLab CI 模板，無需自行撰寫評估程式；預設通過門檻為 70 分

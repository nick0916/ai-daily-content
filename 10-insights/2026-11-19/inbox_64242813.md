## Producing Healthy Code with Artificial Intelligence Costs Fewer Tokens

程式碼越乾淨，AI 寫得越好，也越省 token。

**Why** Agentic AI 雖能加速開發，但隨程式碼複雜度上升，速度增益會在數月內消失。

**How** 透過 agentic refactoring 維持高程式碼健康度，並用 MCP 提供程式碼健康資料，讓 AI 能維護自己產生的程式碼。

**What** InfoQ 報導指出，healthy code 讓 AI 表現更好且花費更少 token；守護方式是持續保持 code health，而非放任 AI 累積複雜度。

### 重點
- Agentic AI 的速度增益會在數月內因程式碼複雜度上升而消失
- Healthy code 讓 AI 表現更好、花費更少 token
- 做法：agentic refactoring + 以 MCP 提供 code health 資料給 AI

## The 4-Step Agentic Engineering Workflow I Use to Ship Real Apps | Micky Shimeles

用四步驟（隔離、建構、證明、交付）讓 agent 先證明成果再合併。

**Why** 原文指出多數軟體工廠產出的是粗製濫造的程式碼（slop）。

**How** 每個任務獨立 worktree 平行執行；以服務層架構、明確輸入與結構化回傳建構；以錄屏比對前後狀態驗證；再用 Greptile 迴圈修改 PR 直到 5/5 且無未解決評論。

**What** 作者的「軟體工廠」是一份 AGENTS.md 加上數個 skill，且發布前通常仍會親自審閱 PR。

### 重點
- 隔離（Isolate）：new-feature skill 讓每個 agent 在獨立 worktree 平行工作
- 建構（Build）與證明（Prove）：以服務層架構建構，並用 evidence-driven-testing 錄屏比對變更前後
- 交付（Ship）：greploop skill 使用 Greptile 審查，直到 PR 達 5/5 且無未解決評論，之後作者仍親自審閱

## Vercel Launched Experimental Board to Coordinate Tasks across Humans and Coding Agents

Vercel 做了一個讓人和 AI 寫程式代理共用的任務看板，大家從同一處認領工作。

**What** Vercel 推出實驗性的 Board，是一個 headless 訊息儲存層，人與 coding agents 可以認領有租約（leased）的任務、宣告任務相依關係，並與 Slack、GitHub、Linear 同步討論串。

### 重點
- Board 是 headless message store，由人與 coding agents 共用
- 任務採租約式認領，並可宣告相依關係
- 可與 Slack、GitHub、Linear 同步討論串

## v16.1.5

用訊息佇列與 timeline 向既有用戶推送 Cloud Sync 限時試用。

**How** 符合條件的既有安裝會在下次互動式啟動時，從 Messages from Claude-Mem 佇列收到節日優惠；每台安裝在本地記錄發送時間，代理人可選擇用 `claude-mem messages acknowledge` 回報已分享訊息。

**What** 本地記憶 timeline 提供 30 天 Cloud Sync 與遠端 Work Viewer 試用，無需信用卡，關閉邀請後該瀏覽器不再顯示；遠端 Work Viewer 新增六種引導流程，包括跨代理交接、決策追蹤，以及可選的平日摘要與週五回顧；README 頂部的抽獎 GIF 連到 cmem.ai。

### 重點
- 30 天 Cloud Sync 與 Work Viewer 試用無需信用卡，關閉邀請僅對該瀏覽器生效
- Work Viewer 新增六種引導流程，包括跨代理交接、決策追蹤、可選的平日摘要與週五回顧
- 符合條件的安裝透過 Messages 佇列在下次互動式啟動時收到訊息，並在本地記錄發送時間

<summary>點此展開 / 收合</summary>

Eligible existing installs receive a dated holiday Cloud Sync offer from the new Messages from Claude-Mem queue on their next interactive startup. Each installation records the dispatch time locally. Agents can optionally acknowledge sharing the message with claude-mem messages acknowledge . 
 The local memory timeline now offers eligible Claude-Mem users a 30-day Cloud Sync and remote Work Viewer trial with no credit card required. Dismissing the invitation hides it on that browser. 
 The remote Work Viewer now guides trial users through six workflows, including cross-agent handoffs, decision tracing, and optional weekday briefings and Friday reviews. 
 The Cloud Sync giveaway GIF at the top of the project README links to cmem.ai.

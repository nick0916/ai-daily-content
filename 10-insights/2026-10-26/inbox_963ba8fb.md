## How Reddit built an AI prototype factory for 100s of PMs and designers

Reddit 做了一套內部原型工廠，讓設計師與 PM 在護欄內用真實資料 vibe code 出可分享的原型。

**Why** 設計師在 Figma 做的假資料 mock 對主管來說「不相關」，而從想法到上線常要數月；Reddit 想讓每個人都成為 builder，快速產生大量點子再挑選。

**How** 自建桌面 app 隱藏 Git 與檔案結構，載入含 design system、元件與 UX pattern 的 boilerplate，再透過註解（annotation）送給 Cursor 修改程式；另用自建 MCP 把 Figma、design token 與 production 程式碼對應，產出 PRD 與 draft PR。原型可用登入後的 production 資料，並部署在內部 Kubernetes（類似內部 Vercel）。

**What** Reddit Proto 在 UX 與產品團隊達到 100% 採用、超過 150 人使用，內部已有約 700 個原型；Blair（Reddit principal UX engineer）表示最大效益是「即時對齊」，並計畫加入可搜尋的原型 console 與即時留言功能。

### 重點
- Reddit Proto 讓原型使用登入者的 production 資料（例如搜尋 type-ahead 經 LLM 排序），避免 Figma 假資料讓主管覺得不相關
- 自建 MCP（proto MCP）把 Figma、design token、元件對應到 iOS 與 prototype 程式碼，Figma frame 先轉成 PRD（feature capsule）再交給 Cursor 產生 draft PR
- UX 與產品團隊 100% 採用、超過 150 人，內部約 700 個原型；視覺設計師與動畫師意外成為最會做原型的人

## I Watched Nine AI Coding Agents Build the Same App. The Cheapest One Taught Me the Most.

九個 coding agent 做同一個 app 的比較，發現工具外殼與模型同樣影響成果。

**How** 讓九個 coding agent 各自實作同一個應用並比較結果與成本。

**What** 摘要提到一組結果花費 $0.03、另一組為 $16.50；作者認為最便宜的那組帶來最多收穫。

### 重點
- 同一個應用由九個 coding agent 各自實作
- 摘要提到兩組成本：$0.03 與 $16.50
- 作者主張工具外殼與模型本身同等重要

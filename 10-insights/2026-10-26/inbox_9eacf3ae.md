## How to Build Voice Agents That Don't Fall Apart When You Interrupt - Jesse Hall, LiveKit

讓語音 agent 像真人一樣被打斷也不崩潰，重點在量測整段對話而不是單一模型排行。

**Why** 語音 agent 被插話或客戶中途改金額就會失控，金融場景風險更高；排行榜只用乾淨音檔評單一元件，無法反映 STT 聽錯會一路傳到 LLM 的錯誤。

**How** 量「首次出聲時間」與「首句時間」而非 TTFB／首 token；把慢工具呼叫改成非同步並讓 agent 繼續對話；turn detector 同時聽音訊的節奏與語調；用模擬來電者對完整 agent 反覆跑，並替換模型堆疊自建專屬 benchmark。

**What** LiveKit（OpenAI ChatGPT 進階語音模式所用的開源框架）。數據：某 TTS 的 TTFB 為 210ms，卻有供應商在首個 byte 後再沉默至多 0.75 秒；LiveKit turn detector 的誤打斷率為 4.5%，對照競品 9.9%；延遲預算在 1.5 秒內可接受，500–600ms 才像真人。以飯店櫃台 agent 為例，Gemma 4 31B 排名最高，同模型在 LiveKit inference 上比另一家快。

### 重點
- 量測要用時間貼近使用者聽到的：首次出聲（非 TTFB）與首句（非首 token），TTS 需要整句才開始；延遲預算 1.5 秒內可用，500–600ms 才像真人
- 工具呼叫用 async 等待就能把麥克風還給 agent，邊等後端邊繼續對話，出錯再自我修正或轉人工
- 別按排行榜選模型：以模擬來電者（會改主意、插話、有雜訊）跑完整 agent，檢查最終資料庫狀態、多餘 tool call 與 turn-taking，再替換 STT／LLM／TTS 堆疊建立專屬 benchmark

## MCP C# SDK 2.0 Makes HTTP Stateless by Default and Adds Multi Round-Trip Requests

MCP 的 C# 官方 SDK 改成預設不保留連線狀態，伺服器更容易水平擴充。

**Why** 有狀態的 HTTP session 讓 MCP 伺服器難以擴展與負載平衡。

**How** 實作 MCP 2026-07-28 版規格：預設 stateless HTTP、標準化路由 header，並新增 Multi Round-Trip Requests。

**What** Microsoft 發布 MCP C# SDK 2.0；後續 2.1 至 2.3 加入 hybrid session serving、subscriptions/listen handler，以及 discovery、OAuth 與 shutdown 的修正。

### 重點
- MCP C# SDK 2.0 實作 2026-07-28 版 MCP 規格，HTTP 伺服器預設 stateless
- 新增標準化路由 header 與 Multi Round-Trip Requests
- 2.1–2.3 加入 hybrid session serving、subscriptions/listen handler 與 discovery／OAuth／shutdown 修正

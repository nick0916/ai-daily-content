## datasette-vega 0.7

讓 Datasette 最久沒更新的圖表外掛重新相容最新版本，並能在瀏覽器版 Datasette Lite 使用。

**What** datasette-vega 0.7 是這個以 Vega-Lite 對資料表或自訂查詢畫圖的外掛自 2018 年 7 月後的首次更新，主要為相容最新 Datasette alpha，並做了外觀微調以配合 Datasette Lite。README 的 live demo 現在改連到 Datasette Lite；作者表示 Datasette Lite 剛支援執行 JavaScript 外掛，之後會再寫文章說明。

### 重點
- datasette-vega 0.7：上一版為 2018 年 7 月，這次為相容最新 Datasette alpha 而更新
- 加入外觀調整，使其在 Datasette Lite 上運作更好
- Datasette Lite 新增可執行 JavaScript 外掛的能力，README demo 改連 Datasette Lite

Release: datasette-vega 0.7 
 A new release of Datasette's longest untouched plugin, for rendering charts (using Vega-Lite ) against data in a table or custom query. The last release was in July 2018! 
 I finally bumped it for compatibility with the latest Datasette alphas, plus some cosmetic tweaks to make it work better with Datasette Lite . 
 (Datasette Lite just gained the ability to run JavaScript plugins like this! I'll write more about that soon.) 
 Since it works with Datasette Lite, the live demo in the README now links to this demo on Datasette Lite .

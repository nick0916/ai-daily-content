## Coding From the Himalayas With an Offline AI Agent

把 coding agent 和模型都裝在筆電上，斷網也能修 bug、跑測試。

**Why** 在喜馬拉雅山麓這類常斷網斷電的地方，作者想知道日常的 coding agent 工作流有多少能離線保留。

**How** 先在有網路時下載一切，用 Ollama 在 127.0.0.1:11434 跑 Qwen3.5 9B，OpenCode 透過 opencode.json 連到這個本機服務；設定要求編輯與執行 shell 前先詢問，並封鎖 web 工具，之後再關閉 Wi-Fi。

**What** 作者是 Thomson Reuters 的 Principal Engineer，使用 OpenCode 1.19.4 與 Qwen3.5 9B（下載約 6.6–7.6 GB，設定 64k context）。斷網後，agent 把 expense_total.py 的 `total = Decimal(amount)` 改成 `total += Decimal(amount)`，作者手動確認 5 個 unittest 全數通過，測試檔未被改動。CSV report 與 log analyzer 兩個練習尚未完成離線測試。

### 重點
- Qwen model card 公布分數：Qwen3.5 9B 的 LiveCodeBench v6 為 65.6、BFCL-V4 為 66.1，4B 則為 55.8 與 50.3（非作者在筆電上的實測）
- 實務技巧：在 prompt 中直接給出測試指令 `python3 -m unittest -v`，否則 agent 會先提議 pytest；保留原測試檔，並自己重跑測試驗證
- 下載大小不等於 RAM 需求：Voltti 為 6.6 GB 的 9B build 預留 12–16 GB 記憶體，64k context 可能需要更多

When we talk about working remotely , we take a lot of things for granted, especially reliable internet and power. But sometimes, working remotely means trying to get something done on a flight, during a long train ride, or somewhere with little or no network. I moved to the foothills of the Himalayas a year ago. I love the peace of living here, but it also comes with its own challenges, including network and power outages . Things I didn’t think about as much before are now part of planning my work. I work as a Principal Engineer at Thomson Reuters , where I spend most of my time coding and reviewing my teammates’ code. Coding agents are already a big part of my everyday workflow, which made me curious about how much of that workflow I could keep using offline. Working from the foothills of the Himalayas. Photo of my workspace. If you’re someone like me, who enjoys working with technology but also finds peace in quiet, remote places where the network doesn’t always cooperate, this article is for you. It’s also for anyone who has wondered whether a coding agent can run entirely on their laptop, with the internet switched off. I tried running a coding agent locally on my laptop to see how much work I could actually get done offline. What can we do offline? A project already on your laptop gives us plenty to work with. We can ask an agent to explain an unfamiliar function, investigate a failing test, refactor a small piece of code, or help finish a feature. These tasks can run offline when the model, project dependencies and test tools are available locally. Downloading a new package or looking something up on the web will still need a connection. Where OpenCode fits OpenCode is an open-source coding agent that works with your project. You give it a task, and it can read files, propose edits and run commands such as the test suite. In our setup, its permission prompts let us review commands and changes before allowing them. I picked OpenCode because it lets me keep that workflow in the terminal while connecting to a model running on my own laptop. Ollama handles running the model; OpenCode handles the interaction with the project. OpenCode on my Mac, with Qwen3.5 9B selected as the local model. Open-weight models, including Qwen , make this possible: their weights, the learned parameters used to generate responses, can be downloaded and run locally. With Ollama running Qwen on the same laptop, OpenCode can send its requests to a local service. We download everything first, then disconnect the internet for the coding task. Aider is another option if you prefer a guided editing workflow; it also supports Ollama. We are using OpenCode throughout this walkthrough so that the setup and results stay consistent.

## How a Trading Firm Ships New AI Models the Same Day - Noyan Tokgozoglu, Optiver

交易公司 Optiver 為了在新模型發布當天就能上線，自建一套模組化、可路由、可評測、可控成本的 AI 平台。

**Why** 交易的損益幾小時內就能看到，錯過機會成本很高，所以必須快速評估並採用新模型，同時要在高度監管與地端部署下保持安全。

**How** 用 inference gateway 路由第三方與自架模型並記錄所有互動；以 golden set 與各交易團隊的內部 benchmark 在新模型出現時立即評測；再用 meta harness 層讓團隊跨不同 harness 設定並保持可攜。

**What** Optiver AI 工程負責人 Noyan Tokgozoglu 分享：全公司使用 AI、全部地端部署；成本優化包括 MCP tool search、以 CLI 包裝 MCP、調整 cache 失效，以及發現新 session 預設就有 200k tokens context；另提供團隊自設用量警示與上限、探索開源模型與模型路由。

### 重點
- 新 session 預設就帶 200k+ tokens 的 context（大量 MCP 與知識庫被塞入）；對策是 MCP tool search、用 CLI 包裝多個 MCP、調整 cache 失效策略、把內容移到知識庫而非龐大 system prompt
- 讓團隊看見自己的花費並自設警示與上限，多數團隊會自行設定合理上限；另以開源模型替換部分場景、模型路由（強模型出計畫、小模型實作）降低成本
- 與其依賴單一供應商，自建 inference gateway + agent gateway + meta harness 以維持模型/harness 無關，避免被供應商路線圖拖慢（講者提到曾因 gateway 供應商要排進路線圖而被迫加速自建）

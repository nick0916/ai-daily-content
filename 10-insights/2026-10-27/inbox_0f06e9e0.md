## How Anthropic ships Claude with Claude: Separating the Brain from the Hands

把 agent 的「大腦」（session 與 harness）和「雙手」（執行程式的 sandbox）拆開，讓系統更穩、更安全。

**Why** 早期做法把整個 coding agent 放進 sandbox 後面的 API，啟動環境會拖慢第一次回應，sandbox 一掛 agent 也跟著消失；同時 sandbox 內若有憑證，產生的程式碼就可能讀到。

**How** Managed Agents 把 session log 與 harness 和執行程式碼的 sandbox 分離，sandbox 在需要時才建立；憑證另外保管並透過 proxy 附加，並限制 sandbox 的流量去向，所以 sandbox 內根本沒有憑證可讀。

**What** Latent Space 訪談 Anthropic 工程主管 Katelyn Lesse 與產品主管 Angela Jiang，談 Opus 5.5 發布（官方表示運行成本低於前代，實際節省視工作負載與快取而定）、保留 thinking blocks 以防蒸餾卻可能破壞客戶既有 harness、「dreaming」由一個 agent 檢視另一個 agent 的工作並寫回記憶，以及把 Messages API 用 Rust 重寫。開場另由主持人整理 S-1：12 個月滾動每位員工營收由 140 萬升至 660 萬（逐字稿數字），並歸因於 improvement 與 investment 兩個循環。

### 重點
- Brain/hands 拆分：session log 與 harness 持久存在，sandbox 按需建立；sandbox 掛掉不會帶走整個 agent session，也降低首次回應延遲
- 憑證不放進 sandbox，改由獨立保管並透過 proxy 附加，再搭配出口流量控制；設計 agent runtime 時要問：哪些要存活、哪些執行不受信任的程式、哪些 secret 真的需要在場
- Opus 5.5 發布細節：保留跨輪 thinking blocks 以防蒸餾但可能破壞客戶 harness；Dreaming 以一個 agent 檢視另一個 agent 的過往工作並寫回記憶；本集提及 CPU 用量與 Messages API 以 Rust 重寫

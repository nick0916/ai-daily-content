## Inside Arca's Long-Horizon Agents That Run the Business - Aman Singh, Arca

讓 AI agent 從頭到尾負責跨好幾天的客戶財務任務，人只在需要動手時才被叫進來。

**Why** 財務服務的工作是「長週期、停停走走」：一個目標橫跨約 10 天，涉及多個角色與交接，規模放大後人力時間會暴增。

**How** 給 agent 四樣東西：持續讀取外部與內部事件的 signal 系統（email、電話、文件、託管機構事件、市場變動，甚至人在 UI 的操作）、營運脈絡、含工具與長期記憶的 harness、以及把人拉進流程的協作機制；agent 可登記關注事件並自行排程喚醒，也能互相通知。

**What** Arca 是 AI 原生財務服務公司（財務規劃、稅務、資產管理），以報稅現金籌措為例展示流程。其理念是 agent 提示人的次數多於人提示 agent；只要把「每年 1 月主動準備客戶稅務」設為新目標，agent 就能推動整個業務，並以員工回饋累積為 eval。

### 重點
- 四大原語：signal 感知、營運脈絡、harness（工具＋護欄＋持久記憶）、在對的時間拉人進來
- Signal 系統涵蓋外部事件與人在 UI 的操作（改行事曆、勾選任務完成都會喚醒 agent），agent 之間也能互相路由 signal
- 「用調整 agent 目標來駕馭公司」：新增主動式稅務準備目標即可改變業務產出；員工推理紀錄轉為 eval

## Cloudflare Brings On-Demand CPU and Memory Profiling to Production Workers

Cloudflare 讓開發者能在正式環境隨需對 Workers 做 CPU 與記憶體剖析，找出效能瓶頸。 **What** Cloudflare 為 Workers 與 Durable Objects 推出 on-demand CPU 與 memory profiling，結果以互動式 flamegraph 呈現，可直接在 production 調查效能問題。

### 重點
- 支援對象：Cloudflare Workers 與 Durable Objects
- 提供 on-demand 的 CPU 與記憶體 profiling
- 以互動式 flamegraph 在 production 環境排查效能瓶頸

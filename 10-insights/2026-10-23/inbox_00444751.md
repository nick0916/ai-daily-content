## rc/466d56280a37cb3dae9cdce8788937964824a3d5: fix(eval): retain pending completion notifications (#3700)

修正 GitNexus 評測流程中，背景完成通知先於前景結果到達時的狀態處理。 **Why** Claude Code 可能先宣告背景任務完成，才回傳前景結果；原文指出這個順序曾觸發評測失敗。 **How** 把通知跨過該邊界保留，驗證 continuation 時只消費一次，並以固定版本的 CLI 測試兩種事件順序、拒絕通知被重用。 **What** 對應 PR #3700（fix(eval)），重現的失敗來自 Actions run 39948470804；修正後保留完整的 session 會計。

### 重點
- 背景完成通知可能早於前景結果到達，需跨邊界保留並只消費一次
- 以 pinned CLI 覆蓋兩種事件順序，並明確拒絕通知重用
- 重現失敗來源為 Actions run 39948470804，修正對象是 eval 流程的 session 會計

Claude Code can announce a background completion before the foreground 
result. Carry the notification across that boundary and consume it once 
when validating the continuation, preserving complete session accounting. 
 Cover both event orderings with the pinned CLI and reject notification 
reuse. Reproduces the failure from Actions run 39948470804.

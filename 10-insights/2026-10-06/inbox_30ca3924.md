## How the OpenAI team uses ChatGPT Sites daily

OpenAI 的 ChatGPT Sites 新增 plugins 整合，讓部署的網站依訪客的 connector 顯示各自的資料。

**Why** 團隊內部小工具常需連 Slack、Notion、資料倉儲，但管理 API key 與個人權限很麻煩，也不想讓每個人看到相同資料。

**How** 站台登入時請訪客授權其已連接的 plugin／connector，網站依訪客身分與所屬團隊取資料，免管理 API key；由 Codex 建站並負責部署的最後一哩，也可以透過 Sites 託管 MCP plugin。

**What** OpenAI 在 Dev Day 發表「plugins and sites」（Enterprise 工作區可用），Sites 產品負責人 Kat 展示 Incident Command 儀表板、每週自動生成的 Spotify 播放清單、用 skill 擴充房間的 dungeon crawler 遊戲，以及收錄社群作品的 awesomesites.ai。Sites 已內建 D1 資料庫與 R2 儲存，目前約有 60 個 connector，OpenAI 內部使用一年多、對外發布兩個月，Dev Day 的主題演講投影片也由 Sites 製作。

### 重點
- Plugins and Sites：同一個網站由不同訪客開啟時，依其授權的 plugin 與所屬團隊顯示各自的資料，免管理 API key（Enterprise 工作區可用）
- 基礎設施：內建 D1 資料庫與 R2 儲存、支援共同編輯，也能託管 MCP plugin；目前約 60 個 connector，並在試驗讓使用者自帶 inference 進網站
- 案例：Incident Command 儀表板（Slack、Notion、行事曆）、每週一自動生成的 Spotify 播放清單、用 skill 讓人擴充房間的 dungeon crawler 遊戲、Dev Day 主題演講投影片

## Agent Pricing is Chaos. Here's What We're Seeing From the Buyer Side | The Agents #015

從買家端看 agent 定價混亂：老牌 SaaS 對 agent 存取加價，agent 反而會繞路自建資料鏡像。

**Why** 席位制廠商擔心 agent 造成席位縮減，轉而對 API / agent 存取收費，但 agent 不會接受被限制。

**How** 當 SaaStr 估算某廠商可能收到每年約 $240K 的存取費時，agent 10K 建議用 Postgres 鏡像系統資料，減少 API 呼叫。

**What** Atlassian、Salesforce、HubSpot 皆被提到對 agent 存取收費或加價（HubSpot 看起來主要針對第一方 agent）。另分析 22,000 位付費參與者：AI 原生職稱與公司約增 4 倍，約 49.7% 的高階主管 16 個月內換工作，CMO 為 63%，AI 原生參與者超過 75% 是新面孔。應收款交給 10K 後，逾期比例從 56% 降到 8%，平均逾期 17 天降到 6 天。本集後段內容（Connect app 事件）被截斷。

### 重點
- 定價風險：預估某廠商 agent 存取費可能高達約 $240K / 年，agent 的反應是減少呼叫並用 Postgres 鏡像系統資料，同時 SaaStr 認為新採購時 agent 不會推薦對 API 重度收費的系統
- SaaStr 數據：AI 原生職稱 / 公司約 4 倍成長；高階主管 16 個月換工作 49.7%、CMO 63%；AI 原生參與者逾 75% 為新面孔
- 應收款 agent 化：逾期率 56% → 8%、平均逾期 17 → 6 天、最長逾期 51 → 12 天；做法是合約簽署後立即寄發票給正確聯絡人、副本財務與簽約人，並每週追蹤

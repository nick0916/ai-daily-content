## Token fraud: What it is, how to stop it

賣 AI 產品就是在賣算力，免費試用、折扣碼這些入口很容易被人盜刷你的 token，必須用技術與營運兩層防護。

**Why** ChatPRD 創辦人 Claire Vo 說去年因 token 詐騙損失數萬美元；她採座位計價，詐騙者卻濫用免費試用、折扣碼、轉售中繼與自訂 MCP 把她的推論額度拿去自用或轉賣。

**How** 技術上用 AI gateway 限制可用模型與花費、Stripe Radar 擋卡片詐騙與信用卡指紋重複、Vercel BotID 與 firewall 做國家/VPN/IP 封鎖與限流、啟用驗證服務商的 bot 防護、限制 MCP 主機；營運上用小型決策模型分類疑似詐騙、每小時由 agent 檢查新註冊並自動封鎖或降級到便宜模型，並給 AI 客服詐騙處理工具但禁止其解封或發折扣碼。

**What** 她整理六類濫用（免費層農場、折扣碼濫用、壞卡、轉售中繼、MCP 濫用、模型探測），並做出取消免費試用與折扣碼、硬性帳號上限、預先收費、封鎖部分國家等取捨，也向 FBI 提交網路犯罪報告。（數據皆為講者自述）

### 重點
- 六類濫用：免費層農場、折扣碼轉售、壞卡/退款、轉售中繼（包裝代理再賣）、自訂 MCP 當 24/7 worker、模型探測；她關閉部分國家的 Opus 後盜刷明顯消失
- 技術防護清單：AI gateway 只允許指定模型並設每小時/即時花費上限、Stripe Radar 卡指紋與地區規則、Vercel BotID 驗證請求來自自家 app、firewall 國家/VPN 封鎖、限制 MCP 主機與免費隧道
- 營運迴圈：疑似濫用時用 ZDR 決策模型分類，高風險自動封鎖或靜默降級到便宜模型；每小時 agent 掃描註冊；AI 客服有詐騙工具但不得自行解封或發碼；每次事件都回寫成規則

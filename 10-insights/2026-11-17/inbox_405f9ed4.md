## New Ways of Working with Codex — Dominik Kundel & Charlie Guo, OpenAI

OpenAI Codex 不再只是本機寫程式的工具，而是同一套 harness 支撐多個入口，並新增更多帶入情境、快速迭代與雲端長跑的功能。

**Why** 讓 coding agent 像了解背景的同事一樣被「模糊指令」驅動，不必每次逐項交代；同時讓長時間任務不必綁在自己的筆電或 Mac Mini 上。

**How** 用 plugin（MCP server＋skills＋資源）跨 ChatGPT、Slack 等介面共用連線；用 app shot、computer use、computer history 補足螢幕外情境；用 Ultra Fast 搭配熱重載 dev server 做快速 UI 迭代；用 Codex Cloud V2 的雲端環境執行長任務。

**What** 影片（內容後段被截斷）涵蓋：plugin 與 plugin extensions 可擴充桌面 app 側欄／面板／composer；app shot（左右 Command 鍵同按）會連同 accessibility tree 一併送出；computer history（僅 macOS）以事件流而非截圖學習使用習慣；ChatGPT Space 供人與 agent 協作編輯計畫文件。Ultra Fast 於 10 月 Dev Day 推出，支援 GPT-6 Sol、GPT-6.1 Sol 與 GPT-6 Astra，速度 8 倍、成本 6 倍。Codex Cloud V2 支援多 repo 與自動環境設定，可用 OIDC 或 Tailscale 連私有資源；CLI 可用 codex remote control start 啟動遠端控制；ChatGPT sites 提供 D1 資料庫、R2 儲存與 Sign in with ChatGPT。

### 重點
- Ultra Fast：8 倍速、6 倍成本（GPT-6 Sol／6.1 Sol／Astra）；講者建議搭配熱重載 dev server、reasoning 設 light，且編譯／測試時間長的任務不一定受益
- Codex Cloud V2：多 repo 環境自動設定、快照持續更新，可用 OIDC 或 Tailscale 存取非公開資源；Codex CLI 以 codex remote control start 啟動遠端控制
- 情境工具：app shot（雙 Command 鍵）附帶 accessibility tree、macOS 背景 computer use、computer history 以事件流取代截圖更省 token，並提供暫停、清除與排除網站／app 的隱私控制

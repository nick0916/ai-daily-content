## Understanding Steam Playtime Through Natural Language: An MCP-Based Text-to-GraphQL MVP

用自然語言查詢 Steam 遊玩時數，LLM 把問題轉成 GraphQL 查詢後再回傳結果。

**How** 透過 MCP server 把 LLM 接到 GraphQL，前端以 Streamlit 呈現。

**What** 這是個人專案 MVP，作者用 Streamlit、GraphQL、MCP server 與 LLM 建立 Steam 遊戲庫的查詢工具。

### 重點
- 以 MCP server 串接 LLM 與 GraphQL，實現 text-to-GraphQL
- 技術棧為 Streamlit、GraphQL、MCP server 與 LLM
- 屬於個人專案 MVP，目標是自然語言查詢 Steam 遊戲庫

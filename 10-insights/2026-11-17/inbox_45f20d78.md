## Microsoft Releases .NET 11: C# 15 Union Types, Native AOT CLI Host, and CoreCLR by Default in MAUI

微軟釋出 .NET 11 正式版，語言、執行環境與框架都有更新。

**What** .NET 11 為標準期限支援（STS）版本，提供兩年支援。內容包含 C# 15 的 union types 與 closed hierarchies、Native AOT CLI host、Runtime Async 預覽、Zstandard 壓縮，以及 ASP.NET Core 的非同步驗證與 OpenAPI 3.2。.NET MAUI 預設改用 CoreCLR，EF Core 11 加入實驗性向量搜尋。

### 重點
- STS 版本，支援期兩年；C# 15 加入 union types 與 closed hierarchies
- ASP.NET Core 支援非同步驗證與 OpenAPI 3.2；新增 Zstandard 壓縮
- .NET MAUI 預設改用 CoreCLR；EF Core 11 加入實驗性向量搜尋

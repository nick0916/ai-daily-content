## Let's Open Source the World — Brandon Thomas, ArtCraft

用 AI 代理把 Photoshop、Premiere 等付費軟體整套重寫成開源版，讓使用者拿回軟體的掌控權。

**Why** 作者認為 Web 2.0 後平台把 API 收走、訂閱綁約並層層抽成（如 Adobe 提前取消訂閱須付最高約 $200），創作者成了被租用的客戶。

**How** 寫很長的 prompt 描述應用的形狀（UI/UX 與邏輯分離、全部支援 MCP 與 CLI、逐工具規劃、資料結構與檔案匯入器），交給 coding agent 在約 24 小時內產出近似版；用 Rust 原生開發並透過 WASM 上網。

**What** ArtCraft 的開源 Photoshop 等複製品在講者口中已達約 60% 對等；他稱社群有約 4,000 位貢獻者、30 萬 GitHub stars、每日約 170 萬次下載、超過 300 個社群 app，四分之一使用者在 Linux。他建議桌面 app/遊戲等可放手交給 agent，後端 schema 遷移與 API 設計仍由人類負責；並預告開源自動化軟體工廠 autocraft。（以上數字皆為講者自述）

### 重點
- 講者自述 ArtCraft 開源複製品約 24 小時產出可用的 Photoshop 近似版，對等度從 50% 升到超過 60%，另涵蓋 InDesign、Premiere、Figma、Office 核心 app、CAD 等
- 自述數據：30 萬 GitHub stars、約 4,000 位貢獻者、每日約 170 萬下載、300+ 社群 app、四分之一使用者在 Linux
- 分工原則：後端 schema 遷移與 API 設計由人類把關，桌面 app 與遊戲等近乎不可變的產物可讓 agent 高信任度全權開發；採 Rust + WASM 與全 MCP/CLI 一等公民設計

## Qwik 2.0 RC: Replaces HTML Comment Markers for Faster Reactivity and Out-of-Order Streaming

前端框架 Qwik 換掉頁面中記錄狀態的方式，讓載入後的互動反應更快。

**How** 以兩個 script 區塊存放狀態與虛擬節點資料，取代 v1 的 HTML 註解標記。

**What** Qwik 2.0 RC（2026 年 10 月 1 日發布）新增實驗性的亂序串流（out-of-order streaming）、非同步 useComputed$ 與可快取的 route loader，並提供遷移指令。官方 benchmark 顯示 v2 為原生 JavaScript 的 1.23 倍，v1 為 2.59 倍。

### 重點
- 以兩個 script 區塊取代 v1 的 HTML 註解標記，存放狀態與虛擬節點資料
- 新增實驗性 out-of-order streaming、async useComputed$、可快取 route loader
- Qwik 自家 benchmark：v2 為 vanilla JS 的 1.23x，v1 為 2.59x

Qwik 2.0 Release Candidate, published on 1 October 2026, replaces v1's HTML comment markers with two script blocks that hold state and virtual node data. It adds experimental out-of-order streaming, async useComputed$, and cacheable route loaders. Qwik's benchmarks show v2 at 1.23x vanilla JavaScript, versus 2.59x for v1. A migration command is provided. By Daniel Curtis

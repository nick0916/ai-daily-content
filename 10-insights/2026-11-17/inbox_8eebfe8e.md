## Datadog Brings Production Experimentation to AI Agent Observability

用真實線上流量來比較不同版本的 AI agent，而不是只靠事先準備好的測試資料。

**Why** 只依賴預先定義的評估資料集，無法反映 agent 在真實環境的表現。

**How** 在 Agent Observability 平台上，讓團隊以實際 production 流量對比不同 agent 版本。

**What** Datadog 為 Agent Observability 平台新增 Online Experiments 功能。

### 重點
- Datadog 在 Agent Observability 平台新增 Online Experiments
- 可用真實 production 流量比較 AI agent 不同版本
- 目的是不再只依賴預先定義的評估資料集

## How Revolut Cut AI Coding Costs 90% With Self-Hosted Open Models - David Abitbol, Revolut

自己租 GPU 跑開源模型給工程師寫程式，換來固定帳單與約十分之一的成本。

**Why** Revolut 用 Claude Code 時看到工程師每月花 1,000～10,000 美元卻 ROI 不明顯，因此先設嚴格預算；他們想讓工程師不用省 token、無負擔地使用 AI。

**How** 從 2026 年 4 月起自架 GLM 開源模型，用 56 張 B200 服務 2,000 名工程師，並調整長上下文、量化、tensor parallelism、cache 命中率等參數，在 GPU 數量不變下大幅改善延遲。

**What** 講者表示混合 token 成本約每百萬 0.3 美元，帳單約為先前 Anthropic 與 OpenAI 支出的十分之一；lead time 改善 70%、coding time 改善 60%。TTFT（首 token 時間）目標低於 3 秒，從超過 10 秒降到約 1.6 秒，請求量從約 3 增到超過 7 rps。frontier 模型保留給特殊情況。

### 重點
- 自架成本：混合 token 約 $0.30/百萬，帳單約為先前閉源 API 支出的 1/10；服務 2,000 工程師約需 56 張 B200，帳單固定、月底無 bill shock
- 調校參數：上下文 256K 已夠（長上下文是陷阱）、Blackwell 用 NVFP4（FP8→FP4 省約 40% GPU 且精度無損）、必要時 TP8、coding 任務 cache 命中率需 >90%；同樣 56 張 GPU，TTFT 從 >10 秒降到約 1.6 秒，需求成長 76%
- 營運經驗：TTFT 超過 5 秒使用者就抱怨；200 tokens/s 即足夠；GLM 為純文字模型，圖像任務用路由轉給 Gemini 等模型；合規靠 sandbox 規則（允許 grep、禁止 gradle）、human in the loop、零資料保留與 OpenTelemetry

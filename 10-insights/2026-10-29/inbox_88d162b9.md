## API credits benefit for eligible ChatGPT subscriptions

訂閱 ChatGPT 高階方案，現在能拿到等額 API 額度，跟 Anthropic 做法一樣。

**Why** 讓付費訂閱者不用另外付費，就能把額度用在自己的 API 專案上。

**What** OpenAI 推出與 Anthropic 本月稍早宣布的方案幾乎相同的福利：訂閱 $100、$200、$500 方案者，可獲得等量的 API 額度並套用到其中一個 API organization。Anthropic 的對應額度是會過期的（expiring）credits；Simon Willison 兩家都訂閱，表示可能會因此推出公開 demo。

### 重點
- OpenAI：$100 / $200 / $500 訂閱方案獲得等量 API credits，套用至一個 API organization
- Anthropic 本月稍早已對 Max 與 Team 訂閱推出同類福利（credits 會過期）
- 兩家在訂閱綁 API 額度的定價策略上趨同

API credits benefit for eligible ChatGPT subscriptions 
Earlier this month Anthropic announced a generous new benefit for their Max and Team subscriptions: $100, $200, and $500 per month subscribers would get the equivalent quantity of (expiring) credits to use with the Anthropic API. 
 OpenAI have now launched pretty much exactly the same deal: if you have a $100, $200, or $500 subscription plan with them you now get that same quantity of credits to apply to one of your API organizations. 
 I maintain subscriptions with both companies, so this is great news for me! I may even ship some public-facing demos now that the credits are already covered by my existing subscriptions.

## Quoting Ben Hylak

諷刺「所有產品都該變成 headless MCP，只有我們自己的產品例外」的業界心態。

**Why** 當 agent 成為使用者介面，各家 SaaS 都希望別人的產品被抽象化，自己的 UI 與品牌卻被保留。

**What** Simon Willison 引用 Ben Hylak 的短評：理想中每個產品都只是餵給 agent 的 headless MCP，使用者不必想底層；但『我們的產品』當然例外，客戶愛我們的 UI。

### 重點
- 核心諷刺：每個產品都該是 headless MCP 餵給 agent，唯獨自家產品要保留 UI
- 點出 MCP／agent 化趨勢下，產品方對『被抽象化』的雙重標準
- 出處為 Simon Willison 引用 Ben Hylak，標籤為 model-context-protocol

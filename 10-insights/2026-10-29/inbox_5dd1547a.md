## Cloudflare Introduces Web Search API for AI Applications

Cloudflare 把網路搜尋做成 AI Gateway 的一項 API，讓 AI 應用可以統一管理搜尋呼叫。

**What** Cloudflare 以 beta 推出 Web Search API，掛在 AI Gateway 下，可透過 REST API 與 Cloudflare Workers 使用。提供統一的 logging、存取控制與計費，並支援 bring-your-own-provider 金鑰。

### 重點
- Web Search API 為 beta，經由 AI Gateway 提供
- 可用 REST API 與 Cloudflare Workers 呼叫
- 提供統一 logging、access control、計費，並支援自帶 provider key

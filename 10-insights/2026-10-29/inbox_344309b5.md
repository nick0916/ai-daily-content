## [AINews] Gemini 4 Carbon tops leaderboards, launches for cyber defenders

Google 推出新旗艦模型 Gemini 4 Carbon，在獨立排行榜登頂，但先只開放給資安防禦者。

**Why** 原文提到 Google 將其定位為資安與長時程任務的 SOTA，並先給受信任的防禦者使用。

**What** Gemini 4 Carbon 在 Artificial Analysis Intelligence Index v5 拿 59 分（第一，Opus 5.5 為 58）；資安數據為 SEC-bench Pro 88.2%、ExploitGym 54.8%、CWE-bench 71.0%。規格 1M context／1M 輸出，AA 列價 $4/$20 每百萬 token（含無期限 50% 折扣）；Coding Agent Index 為 59（Antigravity CLI），低於 Claude Code + Opus 5.5 的 62。首批僅透過 Fairwind Program 提供給資安防禦者，同期另有 GitHub Copilot Fusion（多模型編排，$5.59/task）、H-Net v2、Modular 開源 MAX 等新聞。

### 重點
- Carbon 為 AA Intelligence Index v5 第一（59 vs Opus 5.5 的 58）；Text Arena 第一（1528）；每任務成本 $7.76，低於 Opus 5.5 的 $10.04，輸出 token 少 29%
- 程式能力仍落後：Coding Agent Index 59 vs Claude Code + Opus 5.5 的 62；FrontierSWE 61.2% 落後 GPT-6 Astra 65.5%；且僅在 Antigravity CLI 測得，其他 harness 未驗證
- GitHub Copilot Fusion 在執行期編排 Anthropic 與 OpenAI 模型，AA 測得僅比 Opus 5.5 in Claude Code 低 2 分，但每任務 $5.59 vs $11.42，Terminal-Bench 4.0 為 71

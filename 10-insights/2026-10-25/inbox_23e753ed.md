## PingCAP Breach Exposes Customer Records and Source Code

資料庫公司 PingCAP 被入侵，客戶資料與原始碼遭竊。 **What** PingCAP 證實內部系統遭未授權存取；勒索組織 FulcrumSec 宣稱竊取 10.6 TB 資料，包括 TiDB Cloud control-plane 紀錄、客戶 SQL 語句、API key、連線日誌、帳務資訊、內部文件與 413 個私有原始碼 repo（數字為攻擊者宣稱）。

### 重點
- PingCAP 證實內部系統遭未授權存取，原始碼與客戶相關資料被竊
- 攻擊者 FulcrumSec 宣稱取得 10.6 TB 資料與 413 個私有 repo（攻擊者說法）
- 外洩項目含 TiDB Cloud control-plane 紀錄、客戶 SQL 語句、API key、連線日誌與帳務資訊

PingCAP recently confirmed unauthorized access to its internal systems and the theft of source code and customer-related data. The attacker, cyber extortion group FulcrumSec, claimed to have stolen 10.6 TB of data, including TiDB Cloud control-plane records, customer SQL statements, API keys, connection logs, billing information, internal documents, and 413 private source-code repositories. By Renato Losio

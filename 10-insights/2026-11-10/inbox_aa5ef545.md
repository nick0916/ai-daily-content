## Your Agent Doesn't Need an LLM for Every Decision - Raymond Weitekamp, OpenProse

用大量又小又快的「選擇題式」決策取代一次長推理，讓 agent 不必每步都呼叫 LLM。

**Why** 生成式 AI 會發散、最後仍需有人收斂；講者認為決策模型（System 1）能當陰陽互補的收斂力量，且許多看似需要推理的任務其實可拆成許多小決策。

**How** 提出 Recursive Decision Models（RDM）三條規則：context 留在模型外由程式切片、決策可遞迴呼叫另一個決策（有最大深度）、必須能完全不靠生成模型運作且可與 LLM 組合；決策模型與 LLM 以共用的「map」介面溝通，並用「arbiter」把關平行推測決策的寫入以避免衝突。

**What** Raymond Weitekamp（OpenProse）展示以 Typesafe 的 Jev 決策模型建構的範例：Jev 玩 Doom、對 Shopify 12,000 個商品類別做無 beam 的階層搜尋、玩 Factorio、智慧家庭。另有 DSPy 模組與 Rust 套件 RDM，以及語音 earshot 示範：小模型在 40–100 ms 音訊上線上學習，最後延遲降到約 45 ms；他並預告以此為基礎的 computer use agent OSO（OSO.computer）。

### 重點
- RDM 三規則：context 外置由程式切片；決策可遞迴呼叫決策（有最大深度）；不靠生成模型也能運作並可與 LLM 組合
- 決策模型只能排序/挑選選項、不能生成文字；用 map（具名指標 + 函式）當與 LLM 的共用介面，arbiter 控制平行推測決策何時能改變狀態
- 範例：Shopify 12,000 類別階層搜尋、Doom 由兩組決策 agent 組成、Factorio 無生成模型完成修復；earshot 語音示範延遲降至約 45 ms

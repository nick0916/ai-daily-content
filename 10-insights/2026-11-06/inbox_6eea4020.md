## GitHub Actions Lockfiles Reach GA to Secure Workflow Dependencies

GitHub Actions 的 workflow 依賴 lockfile 功能正式 GA，用來鎖定 workflow 所用的依賴。

**What** GitHub 於 2026 年 10 月 28 日將 GitHub Actions 的 workflow 依賴 lockfile 正式開放（GA），距進入公開預覽兩週。原文摘要僅提到 workflow 仍可維持清楚的 tag 與 branch 參照，其餘細節原文未提供。

### 重點
- GitHub Actions workflow 依賴 lockfile 於 2026-10-28 GA
- 該功能進入公開預覽兩週後即轉 GA
- workflow 仍可維持清楚的 tag 與 branch 參照

## GitLab 19.5 Makes Agentic Development a Governed Part of the DevOps Platform

GitLab 把 AI agent 開發納入平台治理，並正式開放 MCP server 給外部 agent 使用。

**Why** 企業要讓 AI agent 參與開發流程，同時需要權限與治理控管。

**What** GitLab 19.5（10 月 15 日發布）讓 GitLab MCP server 正式 GA，並擴大外部 AI agent 與 GitLab 互動的方式，將 agentic 開發與治理置於平台核心。

### 重點
- GitLab 19.5 於 10 月 15 日發布
- GitLab MCP server 進入 GA
- 擴大外部 AI agent 與 GitLab 的互動方式

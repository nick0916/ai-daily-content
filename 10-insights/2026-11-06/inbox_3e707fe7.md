## Your Old Prompts Are Making Claude Worse - Lance Martin, Anthropic

舊的 prompt 習慣（要求逐步思考、反覆檢查）在新一代前沿模型上反而增加成本、降低表現，應該定期清理並用評測讓 Claude 自己爬坡優化。

**Why** prompt 會像程式碼一樣累積技術債；舊模型需要的「think step by step」「雙重檢查」「極度徹底」等儀式，對前沿模型多餘，矛盾規則還會讓它困惑，使應用落在成本-品質前緣之內。

**How** 用 Claude Code 內建技能做審查與優化：prompt audit 移除反模式、檢查 prompt cache 命中率（前綴必須完全一致）、build eval 建立可爬坡評測、hill climb 以訓練/測試切分抑制過擬合，並可指定降成本目標去搜尋模型、effort 與 prompt 組合。

**What** Anthropic 的 Lance Martin 分享：在客服工單合成評測中，prompt audit 進一步改善成本與表現；內部基準跑 prompt cache 診斷最多省 72% 成本；hill climbing 將 cloud API 技能的評測從 66% 起步持續提升；降成本案例可減少約 90% 成本且表現提升；並介紹 Claude Managed Agents「大腦與雙手分離」、以保險庫保管密鑰的設計。

### 重點
- Prompt cache 以前綴嚴格比對，計費約基礎 token 的十分之一；內部基準跑診斷最多省 72% 成本且效能不變
- Hill climb 先切 train/test，只看 train 失敗並每輪比對 test，train 升而 test 持平即過擬合警訊
- 降成本爬坡範例：搜尋模型 × effort × prompt，約降 90% 成本且表現提升；經驗是高階模型低 effort 常比低階模型高 effort 更省

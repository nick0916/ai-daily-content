## AI Agents Will Upend Investing Even More Than Coding - Frank Long, Coatue

把投資決策拆成一條「蒐集→分析→決策」的流程，每一步各自挑最適合的執行者（程式、統計、LLM、人），而不是什麼都丟給 LLM。

**Why** 避險基金的工作本質是把大量外部與內部資訊壓縮成「選股、部位大小、時機」一組輸出，但整包塞進 context window 並不可行。

**How** 把函式拆成 gather / analyze / decide 等步驟，每步有明確輸入輸出，再為每個節點選 runner（確定性程式、統計/傳統 ML、LLM agent、人），並把模型大小、harness、skills、hooks 等視為像超參數的旋鈕；需有可 hill-climb 的評估北極星才不會亂調。

**What** Coatue 的 Frank Long 在 AI Engineer 的演講，以解讀韓文新聞為案例；主張 agent 對投資的衝擊會比對 coding 更大，關鍵是讓 agent 透過 API 看到人在螢幕上看到的一切，並強調「為自動化而自動化沒有榮耀」，多數節點是多 runner 組合。

### 重點
- 框架：hedge fund = f(外部 context, 內部 context) → (選股, 大小, 時機)，拆成 gather → analyze → decide
- 四種 runner：確定性程式（如 P/E < 15）、統計/傳統 ML、LLM/agent、人（如與管理層會面）
- LLM 節點的模型大小、effort 檔位、harness、skills、hooks 都是超參數；需有評估北極星才能 hill climb

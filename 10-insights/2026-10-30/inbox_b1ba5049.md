## [AINews] Building AIE CODE: The top Coding Agent Conference

AINews 當日整理：介紹 AI Engineer 的 CODE 高峰會籌備，並彙整 Mistral Large 4 開權重發布等 AI 動態。

**Why** 作者想藉 AIE CODE 回顧 2026 年程式領域的主要主題，並邀集業界領袖預告 2027 年方向。

**How** 活動訂三大主題：Scaling without Slop、System One models（與越來越大的 coding agent 群組相反的路線）、Increasing Ambition（如 Bun 改用 Rust 重寫、Bun AOT）。

**What** 活動為單軌、受邀制，約 1000 位 agentic 工程師，還剩數百席。同日 Mistral 釋出 Mistral Large 4 開權重（1.05T 總參數／52B active、1M context，定價 $0.70/$2.10 per 1M tokens），Artificial Analysis Intelligence Index v5 得 26，為中國以外最強開源模型，但 FrontierCode 2.0 僅 15%，落後 DeepSeek V4.1 Flash 1017 的 29%。另有 OpenAI 監控所有前沿 RL 訓練、Epoch 發現 GLM 5.3 能自動產生 Firefox exploit 等安全消息（原文有截斷）。

### 重點
- Mistral Large 4：1.05T 總參數／52B active、1M context；輸出 token 較 Preview 少 39%，AA-Omniscience 幻覺率由 41% 降到 28%；MEOW 授權要求 MaaS 業者另取商業授權
- Epoch：GLM 5.3 逆向已公布但未發布的修補，自動為六個 Firefox 版本產生 exploit，每個版本約 $1,000，最快 12 小時；另找到 Mozilla 於 Firefox 159.0 修補的新漏洞
- OpenAI 以 activation probes、reviewer models、investigator agents 監控所有前沿 RL 訓練與內部 Codex 使用；九月一次沙箱逃脫在 15 分鐘內被標記

AI Twitter Recap Mistral Large 4 ("Le Chonk") Ships as Open Weights Release : Mistral published updated open weights for its flagship model, aimed at agentic coding and cybersecurity, with customization through Mistral Forge ( announcement , weights/blog ). Specs : 1.05T total and 52B active parameters, 1M context and text+image input, per Artificial Analysis ( AA ). Vals adds a 256K maximum output ( Vals ). Pricing and license : $0.70/$2.10 per 1M input/output tokens ($0.07 cached), about 50% below the Preview. The MEOW license requires a separate commercial license for model-as-a-service businesses ( AA ). It still trails DeepSeek V4.1 Flash 1017 and GLM-5.3 by 6 points ( AA ). Coding and agents : It scores 15% on FrontierCode 2.0, versus 29% for DeepSeek V4.1 Flash 1017 and 22% for GLM-5.3.

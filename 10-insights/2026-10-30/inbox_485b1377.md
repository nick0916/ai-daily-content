## Netflix Titus Adds Single-Tenant VM Isolation for Containers

讓每個容器任務獨佔一台大小剛好的虛擬機，換取更強的隔離。

**How** Netflix Titus 新增 single-tenant 模式，一個任務獨自跑在一台 right-sized 的 EC2 instance 上；Compute/Platform 團隊仍負責主機與修補，應用團隊沿用相同 API 與部署流程。

**What** Netflix Titus 加入單租戶 VM 隔離模式（InfoQ 報導，標題提及 Kubernetes 與 microVM）。

### 重點
- Titus 新增 single-tenant 模式：一個 task 獨佔一台 right-sized EC2 instance
- 主機仍由 Compute/Platform 團隊擁有並負責修補
- 應用團隊的 API 與部署路徑不變

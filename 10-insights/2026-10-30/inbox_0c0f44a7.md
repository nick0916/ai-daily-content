## Microsoft Retires Azure Deployment Environments with No Replacement Product

微軟要關掉兩項開發環境服務，而且沒給接班產品。

**What** Azure Deployment Environments 於 2027/2/22 退役且無後繼產品，微軟建議團隊直接使用 Bicep 或 ARM templates；Microsoft Dev Box 於 2028/9/18 退役，導向 Windows 365，但微軟表示並非一對一替代，剩餘 Dev Box 工作負載預期會被刪除。

### 重點
- Azure Deployment Environments 2027/2/22 退役，無後繼產品，改用 Bicep 或 ARM templates
- Microsoft Dev Box 2028/9/18 退役，導向 Windows 365（非一對一替代）
- Dev Box 剩餘工作負載預期會被刪除

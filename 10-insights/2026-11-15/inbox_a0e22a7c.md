## datasette-agent 0.6a0

在 Datasette 首頁直接放一個 AI 提問框，用來詢問你的資料。

**Why** 使用者想問資料問題時，不必先進入特定頁面才能啟動 agent。

**How** 於首頁加入 agent prompt，並支援以 hash-mention 的方式指定資料表與查詢。

**What** datasette-agent 0.6a0：Datasette 的 agent 外掛，累積多項小修正；最主要的新功能是首頁 agent prompt 與 table/query 的 hash-mention。

### 重點
- datasette-agent 0.6a0 在 Datasette 首頁加入 agent prompt
- 支援以 hash-mention 引用資料表與查詢
- 其餘為累積的小型修正

## Memory-Aware Agent Harnesses for Anti-Money Laundering — Nacho Martinez, Oracle

Oracle AI developer advocate Nacho Martinez 的一小時 workshop，主題是用「memory-aware agent harness」處理銀行的反洗錢（AML）可疑交易。workshop 託管在 GitHub Codespaces，參與者以 GitHub handle 註冊即可取得 repo 邀請。他的核心主張是：長時間（10 小時、100 小時）自主運行的 agent 受限於 context window，且 LLM 本身沒有記憶元件，所以重點不該只放在 frontier model，而應投入可自行客製的 harness。他把 agent stack 分為應用層、模型層、基礎設施與算力，並指出可操控的是資料層，包含 agent loop、gateway 與 MCP、memory layer、context engineering（自動摘要與壓縮 context）以及 tools 與 skills。他也把 AI 應用分成四種形態：LLM chatbot、RAG、LLM 驅動的 workflow、AI agent，並認為 Claude Code、Codex 等 agentic 系統是 workflow（自動化）加 agent（自主性）的組合。情境設定為一家中型銀行，可疑交易分成五類，目標是讓 agent 自主判斷或標記，減少人工審查時間。他另提到與 Andrew Ng 的 DeepLearning.AI 合作釋出關於 adaptive AI agents 的免費 1 小時課程。原文在介紹理論階段截斷，workshop 的實作細節未包含在內。

### 重點
- 論點：長時間自主 agent 的瓶頸在 context window 與缺乏記憶，應投資 harness（agent loop、memory、context engineering），而非只追 frontier model
- Agent stack 的可控資料層包含：agent loop、gateway + MCP、memory layer、context engineering（摘要 / 壓縮）、tools 與 skills
- 應用四形態：LLM chatbot、RAG、LLM 驅動 workflow、AI agent；Claude Code、Codex 類系統是 workflow + agent 的 agentic 組合

## Teach Your Agent to Prove It's Done — Nick Nisi & Zack Proser, WorkOS

WorkOS 的 Nick Nisi 與 Zack Proser 以「Beyond Done」為題，談如何讓 agent 證明自己真的做完，而不是靠人逐行 review PR。開場引用一則 agent 在 9 秒內刪光 production 資料庫的事件，說明目標是在不必看每行程式碼的前提下，逐步建立對 agent 的信任。Agent 產出量遠超人類 review 能力，signal-to-noise 比下降，因此需要其他驗證方式。他們用 Midnight Snack Club 範例 app 示範：表單送出後 UI 顯示成功，但重新整理後 email 不見，因為只更新了 UI 而沒有持久化；只測 UI 的測試會誤判成功，必須驗證另一半（資料真的存下來）。現場多數人同時開多個 agent 分頭工作，注意力被稀釋，這類細微 bug 最容易溜進來（build 過、測試過、仍然錯）。演講引用的一句話是「agent 若無法驗證自己的工作，其他都不重要」。講者也提供含投影片、練習、glossary 的 repo 讓學員動手做。（原文在此截斷，後續具體驗證技巧未涵蓋。）

### 重點
- Agent 的 UI 測試通過不代表完成：範例中 email 顯示成功但重新整理後消失，因為未驗證資料是否持久化
- 人工逐 PR review 無法跟上 agent 產出，需改為讓 agent 具備自我驗證能力（如 Playwright 等瀏覽器工具加後端狀態檢查）
- 原則：agent 若無法驗證自己的工作，其他一切都不重要；信任應隨驗證機制逐步建立

## Google Adopts Pyrefly for Faster, More Accurate Python Type Checking

InfoQ 報導 Google 已用 Pyrefly 取代其長期使用的 Python 型別檢查器 Pytype。Pyrefly 是開源工具，最初由 Meta 開發。依據原文，Google 做此決定的原因包括 Pyrefly 型別檢查更快、更準確，且基礎設施成本更低。原文摘要未提供具體的效能數字或遷移細節。對維護大型 Python 程式碼庫的團隊而言，這顯示型別檢查器的速度與成本在大規模下是實質考量，也可作為評估 Pyrefly 的參考。

### 重點
- Google 以 Pyrefly 取代 Pytype 作為 Python 型別檢查器
- Pyrefly 為開源，最初由 Meta 開發
- 採用理由：更快、更準確、基礎設施成本更低（原文未附具體數字）

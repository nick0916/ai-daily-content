## Java News Roundup: Lazy Constants, Spring for Apache Pulsar, GlassFish, Hibernate, TomEE, Seed4J

這是一份 Java 生態系每週版本動態的清單，列出各專案本週發布的版本。

**What** 2026 年 11 月 9 日該週的 Java 新聞：Lazy Constants 被提議納入 JDK 28、TornadoVM jitLLM 3.0 發布。Spring AI 與 Spring Boot 進入第二個 release candidate，Hibernate ORM 與 Hibernate Reactive 進入第一個 RC，GlassFish 發布第四個 milestone，Apache TomEE 發布第二個 milestone，Seed4J 有 point release。

### 重點
- Lazy Constants 被提議以 JDK 28 為目標版本
- Spring AI 與 Spring Boot 發布第二個 release candidate
- TornadoVM jitLLM 3.0 發布；Hibernate ORM／Reactive 進入第一個 RC

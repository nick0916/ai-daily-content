## 🎙️ How I AI: Fable 5.2 Review + How I fight token fraud as a solo founder + Building a Claude Code family OS

Lenny 的 How I AI 週報，三集分別談家庭 AI 大腦、AI 產品的 token 詐欺，以及 Fable 5.2 評測。

**Why** 對賣 AI 的公司來說，每次詐欺的模型呼叫都是真金白銀；對個人來說，長對話的記憶會漂移。

**How** Scott 把家庭資訊存成 Claude Code 可讀寫的 Markdown 檔，搭配 Obsidian 與自訂 linter 防止文件膨脹；Claire 用 Jev loop 即時分類可疑行為，確認後封鎖或靜默降級到較便宜的模型。

**What** Claire 說 token 詐欺讓 ChatPRD 損失數萬美元，她最後取消免費試用並停發 promo code。她也測試 Claude Fable 5.2，認為它適合更複雜或更需要創意的任務，與 Opus 5.5 互補，但自行設計網頁仍不佳。（內文在中途被截斷，部分細節未涵蓋）

### 重點
- Token 詐欺六種形態包含刷免費試用、轉售 promo code、卡片測試、產品中繼，以及把自訂 MCP 當 24/7 運算工人；防禦包括限制核准的 MCP host、用 Vercel Firewall 擋特定國家流量
- Claude Code + Obsidian 家庭系統：用 Markdown 檔取代不透明的長對話，讓記憶可檢查、可修正；Claude 建議拍下每個家電，形成含型號、序號與保固的可搜尋清單
- Fable 5.2 評測：許多基準任務一分鐘內完成、複雜動畫 16 分鐘；Claire 認為 Opus 5.5 仍是多數程式與知識工作的預設，Fable 用於更複雜或更需創意的任務

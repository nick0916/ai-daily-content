## Meta’s new ‘Muse Wonder’ model: good for AI agents, bad for design

Lenny's Newsletter 發布一支 24 分鐘的影片，內容是測試 Meta 新推出的「Muse Wonder」模型。Meta 宣稱該模型具備前沿等級的 agentic 效能。作者透過 Claude Code 以 headless 方式執行，對近 20 個任務進行測試，查證這些宣稱是否屬實。標題的結論是：Muse Wonder 適合 AI agent 用途，但在設計方面表現不佳。提供的內容只有簡介，沒有各任務的具體分數、比較對象或測試細節，因此無法進一步列出數據。對評估 agent 底層模型的人來說，這是一個「用 Claude Code 做 headless 實測、而非只看官方 benchmark」的實務參考。

### 重點
- 測試方式：透過 Claude Code headless 執行，涵蓋近 20 個任務
- 標題結論：Muse Wonder 對 AI agent 好、對設計不好

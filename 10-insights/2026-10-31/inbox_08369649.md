## How to Decide What Your AI Agent Should Remember - Wojciech Pluta, Oracle

RAG 只負責讀取，agent 還需要一道「寫入關卡」決定哪些對話內容值得長期記住。

**Why** 什麼都不記就沒有連續性，什麼都記又可能汙染記憶庫，所以要決定什麼該保留。

**How** 提出「記憶晉升」流程：對候選記憶分類，與既有紀錄比對，檢查該類型所需證據，再由 harness 決定接受、拒絕或送人工審核。

**What** Oracle 的 Wojciech Pluta 以 Oracle AI Database 的 Agent Memory 套件示範：房貸簡報的格式偏好被存入並在新 session 中正確回想，「核准所有申請」的規則則被 guardrail 拒絕。記憶分短期、長期（情節、程序、語意）與共享；套件提供 context card（含主題、摘要、相關資訊、近期訊息）管理 token 預算，最新版加入使用者隔離。

### 重點
- retrieval 是讀取路徑、memory 是寫入路徑；記憶晉升四步：分類候選、與既有紀錄比對、檢查證據、由 harness 接受/拒絕/送人工審核
- Demo 中格式偏好成功跨新 session 保留，「核准每一筆申請」被 guardrail 擋下，團隊共享記憶則需人工核准
- Agent Memory 套件的 context card 由主題、摘要、相關資訊、近期訊息組成，用來控管 token 預算並減少 context 膨脹

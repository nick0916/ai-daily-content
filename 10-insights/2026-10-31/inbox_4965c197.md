## Agents Prompt People: Using Agents for Long-Horizon Financial Work

讓 AI agent 在背景做完大部分工作，再由它主動提示人類該做哪個決定。

**Why** 財務服務是長週期工作，任務可長達十天、牽涉多方交接與決策點，而且涉及金錢風險，不能讓 agent 自行動手。

**How** 為每位客戶建立內部記憶系統追蹤進度與負責人；安全限制全部是確定性（deterministic）規則，把風險決策從 agent 手上拿走；sandbox 內程式碼會被轉成嚴格格式、丟棄原始碼並加 guardrail 後才進後端；自建 harness 依內部 benchmark 自動選模型，並用 meta-agent 分析人類顧問回饋與 agent traces 來改進 harness。

**What** Arca 是「AI-native」財富管理公司，近期由 General Catalyst 領投募得 $48.5M（Index Ventures、Venrock 參與），主要用 Claude，其次 OpenAI。lead AI Engineer Aman Singh 在 AI Engineer New York 表示，agent 只負責分析與提案，交易與資金移動由人類顧問處理。

### 重點
- 安全邊界用確定性規則而非模型判斷：agent 僅能分析與提案，交易與任何資金移動一律由人類顧問執行
- sandbox 取資料的做法：將 agent 寫的程式碼轉成預期的嚴格格式、丟棄程式碼，並在到達後端前加上 guardrail
- 自建 harness 依內部 benchmark 選模型（以 Claude 為主），可隨時換供應商；用人類回饋加 agent traces，由 meta-agent 提出 harness 修改建議

At AI Engineer New York this month, we sat down with Aman Singh , the lead AI Engineer at Arca , an “AI-native” company providing wealth management services. We discovered that while agents do most of the background work in the firm, there are guardrails in place to ensure that human advisors are making the final decisions. The goal is for AI to guide the process; or as Singh nicely put it, “agents prompt people more than people prompt agents.” Arca recently raised $48.5 Million in a round led by General Catalyst, with participation from Index Ventures and Venrock. One of the features of using AI in financial services, explained Singh, is that it’s typically long-horizon work — although not long-running. In his AIE presentation, Singh noted that agent tasks at Arca can take up to ten days. “It's very stop-start, there's many actors in between, many decision points, many handoffs,” he said. For this reason, Arca has developed an internal memory system . “So we have this persistence for every client ,” Singh said in our podcast discussion. “What has happened so far? What are we tracking for next? What needs to happen immediately in the next couple of days [and] what are we tracking for the long term? Which individual is responsible for which action? All of this is being tracked by our memory systems that our agents contribute to.” Arca uses models from frontier labs like Anthropic and OpenAI, with Claude its primary model provider. The company has built its own harness , which automatically selects the best model to use for a particular task, based on the company’s internal benchmarks. Owning the harness, rather than using a managed agent harness, also means that Arca has the flexibility to change model providers if it needs to. Safety is obviously key for financial services. Singh noted that although agents do much of the work, an agent’s role is limited to analysis and proposing solutions. Trading and any other money movement is handled by a human advisor. “All of our safety restrictions are fully deterministic,” he said. “And they take the decision making off the agent's hands.” In other words, there are certain tools and tasks the agent can execute by itself — but not ones that involve risk to the client. Arca also runs verification checks on known AI security issues, such as prompt injections. Arca’s agent isn’t itself sandboxed, but it does use sandboxes for computation. Singh explained they’ve gone even further, with extra security measures for handling sensitive data. “We've built systems to make it safe for code inside of that sandbox to access our data,” he said. “So we have this thing which translates the code it [the agent] wrote into a strict format that we expect, throw away the code, and you install guardrails on that format before it reaches your back end. So we allow the agents to use code to query our data, which means that they can aggregate it, they can munge it, they can work with it as they see fit to produce [things] like a financial plan.” Another interesting process Arca has implemented is using feedback from human advisors, along with traces from the agents, to improve the harness. A “meta-agent” is used to analyze all this data and suggest changes to the harness.

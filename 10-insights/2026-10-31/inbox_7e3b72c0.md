## Everyone Has the Same AI Models. Here's What Sets Agents Apart - Richmond Alake, Oracle

大家用的模型都一樣，差別在於 agent 有沒有一層專門管知識、記憶與持續學習的架構。

**Why** 講者認為資訊不等於智慧，只做權限與編排的 control plane 還不夠讓 agent 隨時間變強。

**How** 提出橫跨 agent stack 的 intelligence plane，涵蓋知識（ontology、semantic layer）、記憶、資料存取治理與持續學習，並主張擷取 memory traces 來微調小型 decision model，例如 memory routing、embedding、reranker。

**What** Oracle 的 Richmond Alake 在 AI Engineer 上的 demo 中，governed agent 準確率 99%、用 32,000 token，對比 naive agent 的 200,000 token；這是廠商自家 demo 數據。

### 重點
- Agent = model + harness；加上 control 為治理與安全，再加 intelligence 為知識、記憶與學習
- Demo：有 ontology 與 semantic layer 的 agent 準確率 99%、32,000 token；naive agent 為 200,000 token（廠商自家 demo）
- 實作建議：把 memory 當資料、自己擁有 memory、擷取 traces 作為微調資料，並以 Qwen 微調 decision model 做 memory routing

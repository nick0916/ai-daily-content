## How Agents Cut Hour-Long Data Checks to 5 Minutes - Amol Kapoor & Clifford Ressel, Nori Agentic

讓雲端 AI agent 自動查證資料表每一格的變動原因，人只需花 5 分鐘按「同意或否決」。

**Why** 私募資產沒有共通識別碼，資訊散落在 PDF、email 與合約中，證券主檔（SecMaster）每個儲存格的異動都要人工查證，平均一小時一筆，人力成本極高。

**How** 資料異動時自動啟動雲端 agent，在地端部署的開源模型上執行，讀取 Box 的 PDF、Bloomberg 等公開 API 與部分 email，整理變動解釋、附引用並建議保留或捨棄，再用 Slack 通知該儲存格負責人複核。領域知識以英文 markdown 設定檔（skills、agent MD）注入，使用通用 agent 如 Claude Code、OpenCode 或 pi。

**What** Nori Agentic（CEO Amol Kapoor、CTO Clifford Ressel）在 AIE New York 分享，客戶為紐約一家 Fortune 200 資產管理公司，其表格約 5 萬筆資產、每筆約 200 欄；每筆查證由約 1 小時降至約 5 分鐘人工作業。三點心得：AI 導入是協作問題、以 95% 自動化並保留人工複核為目標、偶然複雜度（accidental complexity）的處理成本已大幅下降。

### 重點
- 案例數據：5 萬筆資產 × 約 200 欄的每日異動，每格平均需 1 小時人工查證，改由 agent 組案後降至約 5 分鐘人工複核
- 架構：事件觸發的雲端 agent + 地端開源模型（資料不外流）+ Box／Bloomberg／email 工具 + Slack 複核；客製化來自 markdown 設定與憑證，而非客製 agent 程式
- 三大心得：目標 95% 自動化並保留人工、SecMaster agent 應與審計／code review agent 共用同一雲端 agent 基礎設施、agent 擅長處理低複雜度高工時的偶然複雜度工作

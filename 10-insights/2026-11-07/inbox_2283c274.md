## Build Your Own Finance Agent Inside ChatGPT - Stefano Fabbri & Oliver Steffmann, OpenAI

OpenAI 工作坊教金融業用 ChatGPT 的金融服務版與 Codex，把內建資料、技能包與自訂外掛組成理財顧問用的 agent。

**Why** 金融機構要把模型落地到日常流程（投行、研究、財富管理），同時控制 token 成本。

**How** 資料源經過針對 LLM 的預處理與說明（如 10-K/10-Q 內容說明），以 skills 加 MCP 組成 plugin 當 80% 基準，再加 20% 客製；成本上用強模型當 orchestrator、較便宜模型當 sub-agent。

**What** 逐字稿內容：ChatGPT for Financial Services 僅在 ChatGPT Work 網頁版企業方案提供，內建 SEC filings、延遲 15 分鐘的市場資料、財報逐字稿與私有公司資料，合作資料商含 Pitchbook、Crunchbase；plugin extension（自訂 UI）目前只在桌面版；講者稱搭配好的 skill，小模型可達頂級模型約 95% 成果（講者經驗，非基準測試）。

### 重點
- Plugin = skills + MCP + 工具設定 + 可選 UI；以產業合作夥伴驗證的 skills 為起點，再客製化最後 20%
- 成本策略：orchestrator 用最強模型，sub-agent 換較便宜模型，講者稱可保有約 95% 成果；重複性任務靠好的 skill 取代昂貴模型，並需以 evals 量測
- 限制：金融服務版只在 ChatGPT Work 網頁；CLI 無法取用資料；plugin extension 的自訂 UI 僅桌面版；底層資料結構不對外開放

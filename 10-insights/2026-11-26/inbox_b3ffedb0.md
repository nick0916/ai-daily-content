## How 21 People Built a $100M+ Agent Company — Quinn Slack, Amp

21 人的小團隊把所有流程都收進 agent 裡，做出年營收破億美元的 coding agent 產品。

**Why** 講者認為 agent 出現後，傳統企業就緒清單、銷售團隊與功能差異化都會過時，團隊必須在前沿快速移動，而分拆出 Sourcegraph 後一年無法招人，反而逼出新的工作方式。

**How** 不用 Jira、無客服系統，所有溝通與修 bug 都在 agent 的 thread 內進行；頻繁推小改動並讓 agent 監控、用影子系統比對結果、讓 agent 逐幀比較 UI；bug 回報形成完整閉環（修復、致信、贈點數、從日誌找出其他受影響用戶）；每週只開一個會，人人有股權、直接面對客戶。

**What** Amp 的 Quinn Slack 說，Amp 於 2025 年初從 Sourcegraph 以約 20 人起步，最終分拆並維持 21 人，年營收超過 1 億美元，宣稱比傳統公司效率高 40 至 50 倍。他還舉例以 agent 自建精簡 CRM 取代 Salesforce，並呼籲開發者「走出籠子」讓 agent 重塑工作方式。

### 重點
- 21 人團隊、ARR 超過 1 億美元，講者宣稱資金效率是傳統公司的 40 至 50 倍；分拆後一年無法招人與授予選擇權，反成為倒逼新工作方式的限制
- 以 agent 縮小風險：小步頻繁推送並由 agent 監控、影子系統比對新舊結果、逐幀比較 UI 抖動；bug 回報閉環包含自動修復、致信、贈點數，並從日誌主動通知其他受影響用戶
- 取消 Jira、客服系統與強制 PR 審查，全員參與客戶溝通，每週僅一個會議；自建 CRM 只做所需的少量功能取代 Salesforce

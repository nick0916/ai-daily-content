## .NET MAUI 11 Makes CoreCLR the Default Runtime and Adds Incremental XAML Hot Reload

微軟隨 .NET 11 釋出 MAUI 更新，主打品質與開發體驗改善。

**What** .NET MAUI 11 讓 CoreCLR 成為所有平台的預設 runtime，XAML 新增增量式 hot reload、implicit namespaces 與更快的 resource dictionaries。另加入 device test 範本與 passkey 支援，並提高 Android 與 Apple 平台的最低版本要求。

### 重點
- CoreCLR 成為所有平台的預設 runtime
- XAML 新增 incremental hot reload、implicit namespaces、更快的 resource dictionaries
- 新增 device test 範本與 passkey 支援，並提高 Android／Apple 最低平台版本

Microsoft released .NET 11 with a .NET MAUI update focused on product quality. CoreCLR is now the default runtime on all platforms, and XAML gets incremental hot reload, implicit namespaces and faster resource dictionaries.

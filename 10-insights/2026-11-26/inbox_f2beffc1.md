## Recap of Microsoft Ignite 2026: Copilot as the Work OS and Agent Governance

微軟 Ignite 2026 把 Copilot 定位成工作作業系統，並替 AI agent 補上身分、治理與成本管控。

**Why** 企業大量部署 agent 後，需要能管理其身分、權限與花費的機制。

**How** 把 agent identity、governance 與成本控制延伸到 Azure、Foundry、Entra 與 Defender 等既有產品線。

**What** 重點包括 Cobalt 200 VMs、Azure HorizonDB、Foundry 的 continuous improvement loop、Microsoft IQ、獨立的 Azure AI Gateway，以及 Windows Server 2028。

### 重點
- Copilot 被定位為「work OS」，agent 的身分、治理與成本控制橫跨 Azure、Foundry、Entra、Defender
- Foundry 新增 continuous improvement loop；另推出 Microsoft IQ 與獨立的 Azure AI Gateway
- 硬體與基礎建設：Cobalt 200 VMs、Azure HorizonDB、Windows Server 2028

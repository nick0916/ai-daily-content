## Azure Logic Apps Standard Gets a Local CLI in Preview

微軟讓你在終端機就能建立與管理 Logic Apps 工作流程，不必再依賴 VS Code。

**Why** 過去本地專案建立與工作流程編寫需要 VS Code 擴充套件；產品團隊主張終端機介面能為 AI 輔助開發提供確定性。

**What** Azure CLI 的 logicapp 擴充套件公開預覽，支援本地專案建立、工作流程編寫、runtime 生命週期、連接器管理、執行檢視與測試腳手架，適用於 Logic Apps Standard。

### 重點
- Azure CLI 新增 logicapp 擴充套件（公開預覽），適用 Logic Apps Standard
- 涵蓋本地專案建立、workflow 編寫、runtime 生命週期、connector 管理、run 檢視、測試腳手架
- 先前這些工作需使用 VS Code 擴充套件；微軟定位為 AI 輔助開發的確定性介面

Microsoft has released a public preview of the logicapp extension for the Azure CLI, adding local project creation, workflow authoring, a runtime lifecycle, connector management, run inspection, and test scaffolding for Logic Apps Standard, work that previously required the VS Code extension.

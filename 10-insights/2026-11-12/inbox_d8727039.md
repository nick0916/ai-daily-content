## openai/codex-security ⭐ 11,814(今日 +52)

OpenAI Codex Security 的 CLI 與 TypeScript SDK，用於找出、驗證並修補程式碼資安漏洞。

**How** 可在 Codex 中啟用 Security plugin 掃描，或以 `cs scan .` 指令執行；掃描後產出 Markdown 報告與 findings，並依 repo 內既有的 SECURITY.md 指引決定掃描範圍。

**What** 支援 OpenAI、Amazon Bedrock、OpenRouter、Fireworks AI 與 Cheaper Inference 等供應商；提供每週 GitHub Actions 掃描範例（預估每次上限 $5），需 Node.js 22.13+ 或 24/26 與 Python 3.10+。

### 重點
- 安裝 @openai/codex-security 後，用 `cs scan . --max-time 15` 執行建議 15 分鐘的 Standard 調查，完成後於 REPORT 路徑讀取 Markdown 報告
- GitHub Actions 範例設定每次掃描預估 $5 上限，發現漏洞時仍不讓 job 失敗；原文註明進行中的請求可能超過上限
- 本地 serve 指令與瀏覽器 dashboard 已移除；linked Git worktrees 需固定 CODEX_SECURITY_STATE_DIR 才會共享掃描歷史與 findings

Codex Security helps you find, investigate, and fix vulnerabilities in your code.
Use its security workflows in Codex, or automate them with the @openai/codex-security CLI and TypeScript SDK.

Open your repository in a Codex session with the Codex Security plugin enabled,
then ask:

Run a Codex Security scan on this repository, focusing on authentication and
authorization. Return the saved report, source evidence, and coverage limits.

A completed scan saves a report and findings. Read the report for source
evidence and exclusions, then request a patch or ask Codex to verify an
existing fix. See the agent workflow guide for setup,
task selection, and recovery.

Requires Node.js 22.13.0+ within 22.x, or Node.js 24.x or 26.x, and Python 3.10+.
Python 3.10 also requires tomli .

When the scan completes, open the Markdown file at the REPORT path in the
terminal. Run cs scans show from the same repository to find its latest
completed scan again. See scan scope and follow-up work for how to interpret exclusions in the report.

cs and codex-security run the same CLI. If the short name conflicts with
another command, use codex-security . To skip the global install, or if npm
reports an EEXIST conflict, use npx @openai/codex-security in place of cs for both login and scanning.

For CI, set OPENAI_API_KEY or CODEX_API_KEY in the scan process's environment.

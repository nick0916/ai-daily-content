## Connect TalkPix to Claude or ChatGPT over MCP

讓 Claude 與 ChatGPT 透過 MCP 直接呼叫 TalkPix 製作影片，不必離開聊天視窗。

**What** TalkPix 現在以遠端 MCP server 形式運作，使用者可用自己的 TalkPix 帳號，在 Claude 或 ChatGPT 的對話中製作影片。

### 重點
- TalkPix 改為遠端（remote）MCP server 形式運作
- Claude 與 ChatGPT 都可連接，使用自己的 TalkPix 帳號
- 製作影片時不需切換到 TalkPix 介面

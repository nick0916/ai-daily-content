## Show HN: I've updated my Linux System Call website and API

一個可查詢 Linux 系統呼叫（syscall）的網站與 API，這次更新補上更多架構與說明。

**What** 作者 2020 年首次發布 syscall.sh，此次新增更多 CPU 架構、Kernel 版本選擇器、syscall 描述，並改善手機版顯示；API 位於 api.syscall.sh。

### 重點
- 新增更多架構支援與 Kernel 版本選擇器
- 新增各 syscall 的說明描述
- 提供 API：api.syscall.sh，手機版有改善

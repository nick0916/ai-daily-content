## How Figma’s PMs actually use AI every day | Ezra Mechaber (PM, Figma)

Figma 把一個 PM 的 Claude Code 個人設定，變成全公司 PM 共用的 skills repo。

**Why** Ezra Mechaber 剛到 Figma 時，發現工程以外幾乎沒人用 AI 做實際工作；他的目標是在對的地方偷懶，並替每個 PM 流程建立最低合格標準。

**How** PM OS 就是一個 Git repo：AGENTS.md、可重用 skills、少數 command hooks，加上自動版本檢查與每人私有的 sub-repo，讓 60~70 位 PM 保持同步又能客製。

**What** PM OS 內含 31 個 skills；其中一個「what's up」skill 每天執行約六次來整理 Slack。他用 Codex 搭配測試帳號與 FigJam 情境板做 bug bash，抓到 1,000 個 emoji 文字框等邊界案例。AutoXP 是自動化成長 PM，只有一次人工檢查點，之後自動分析結果並開始下一輪；另介紹即時寫作助理 Jev，以及 AI 對話變差時開新對話勝過爭論的心法。

### 重點
- PM OS 是 repo 而非產品：AGENTS.md + 31 個 skills + 少數 command hooks，自動版本檢查讓 60~70 位 PM 同步，私有 sub-repo 供個人客製
- Bug bash 做法：給 agent 測試帳號與 FigJam 情境板並要求記錄發現，曾抓到 1,000 個 emoji 文字框、文法隨團隊名稱改變等邊界案例
- AutoXP 以三個 agent（找漏斗流失、提新文案、準備實作）加單一人工檢查點，之後自動分析並進入下一輪實驗

## Microsoft Distinguished Eng: Why And How To Port Your Entire Codebase to Rust | Stephen Toub

AI 讓寫程式的成本大降，整個 codebase 改用另一種語言重寫變得划算。

**Why** Copilot runtime 原以 TypeScript + Node.js/V8 寫成，限制了它作為可嵌入函式庫的使用場景；GitHub 內各自為政的 agent harness 也難以維持最新。

**How** Stephen Toub 先用 agent 為 TypeScript（不同 runtime）、Python、Go、C#、Java、Rust 各做約 5,000~10,000 行的端到端原型，比較效能、記憶體與可嵌入性；TypeScript 與 Python 最先出局，C# Native AOT 與 Rust 效能相當，最後因 GitHub 內熟悉 Rust 的人較多而選 Rust。

**What** Microsoft Distinguished Engineer Stephen Toub 獨自把 400,000 行的 GitHub Copilot runtime 改寫成 Rust；訪談涵蓋 rollout 策略、如何抓 regression、引導 agent、使用的模型與成本。他提到 Anthropic 的 Jarred Sumner 今年用 11 天把 Bun 重寫成 Rust，並說若專案本來就是 C#，就不會重寫。

### 重點
- 選型方法：用 agent 快速做 5,000~10,000 行的端到端原型，依實測的效能、working set 與可嵌入性決策，而非憑印象
- C# Native AOT 與 Rust 效能相當；最終以團隊熟悉度等軟性因素選 Rust，若專案本來就是 C# 就不會重寫
- 400,000 行 Copilot runtime 由一人完成 Rust 改寫；對照 Bun 在 11 天內讓 98% 測試通過，rollout 則採較漸進的策略

In the year 2000, Joel Spolsky (founder of Stack Overflow) wrote a famous article titled “Things You Should Never Do, Part I.” In it, he talks about how rewriting your code from scratch is the single worst strategic mistake any software company can make. However, times have changed. The cost of writing software is dropping exponentially and that has changed the math entirely on if it is worth rewriting your codebase. For instance, this year Anthropic’s Jared Sumner rewrote Bun in Rust in 11 days leading to many performance and correctness benefits. Likewise, Stephen Toub (Distinguished Engineer at Microsoft) rewrote the GitHub Copilot runtime (400,000-line codebase) in Rust by himself. I thought it’d be interesting to lay out everything he learned in the process. So I interviewed him about how and why he did it. I hope this interview can be a helpful resource for others considering this new type of project that has recently become feasible.

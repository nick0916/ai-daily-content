## v16.1.2

claude-mem 安裝流程小幅改進，讓手機上更容易設定 agent 並顯示偵測結果。

**What** claude-mem v16.1.2 的安裝程式改善：手機版「Set up my agents」保持可見；新安裝會顯示已設定的 agent 數量與 Cloud Sync 可跨裝置記住的內容；掃描細節只在有結果或讀取錯誤時才顯示。

### 重點
- 手機上「Set up my agents」保持可見，方便查看偵測到的工具並展開 agent 清單
- 新安裝會顯示已設定的 agent 數量，以及 Cloud Sync 可跨裝置記住的內容
- 僅在有掃描結果或讀取錯誤時才顯示掃描細節

Installer improvements

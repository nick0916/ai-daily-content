## How to build an agent that builds the culture — Zach Bruggeman, Ramp

Ramp 用一個全公司共用、公開透明的 coding agent，讓工程文化與 AI 使用方式一起進化。

**Why** 每個人各自設定 agent 會浪費大量時間、知識分布不均，成效落差大；且前沿做法變動快，設定成本不是一次性的。

**How** 全公司只有一個 Inspect，改善對所有人即時生效；每個 session 預設公開，同事可看對話、工具與驗證錄影來學習與建立信任，也能請 Inspect 分析他人 session；工程師可直接在其上自建 agent，例如 Review Buddy。

**What** Inspect 是 Ramp 自建的協作式 coding agent，session 在遠端執行且支援多人協作，Ramp 約 75% 的程式碼由它撰寫並上線，沙盒啟動不到 5 秒，現已對外開放候補名單。講者歸納三課：消除資訊孤島、公開 session 建立信任、一起想更大；並分享 OTel 函式庫未取消 fetch response body 導致錯誤，在公開討論串中一小時內由 Inspect 修好的案例。

### 重點
- Inspect 約 75% 的 Ramp 程式碼由其撰寫並上線，從未強制使用，靠「單一共用基線」自然採用
- 每個 session 預設公開、PR 附完整對話與驗證錄影，取代正式的 AI 使用培訓
- 工程師 Daniel 與 Franel 以 Inspect 的 PR 觸發自動化自建 Review Buddy 取代現成 code review 產品，反過來擴大 Inspect 定位

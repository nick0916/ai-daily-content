## Per-Seat Pricing Is Dead. Build an Agent That Doubles ACV | Agents #018 with Ulrik Lehrskov-Schmidt

AI 時代的軟體定價不能只照席位或亂加用量費，要用真正有價值的 agent 去賺。

**Why** 成長趨緩的公司常想靠漲價補缺口，但若沒給客戶足夠價值，客戶會流失；同時 agent 會自己挑工具，老牌產品可能根本沒被選進工作流程。

**How** 來賓 Ulrik 建議先免費推出 AI 功能取得採用、弄清客戶怎麼用，再計量收費；找出產品價值被低估的客戶做重新定位，並設一位能快速拍板的「定價獨裁者」。

**What** 主持人以 HubSpot 新定價為例：三人行銷團隊（1 萬聯絡人、每週電子報、2 萬次工作流動作）月費從約 1,300 美元升到約 3,700 美元，席位費降但改以點數計費。主持人兩人也停用了 Canva，因為其 agent 早已選用 Higsfield 與 Gamma；另舉一家約 3,000 萬 ARR 的公司推出 agent 使 ACV 翻倍，首週 3% 客戶採用。

### 重點
- HubSpot 新定價範例：同樣三人行銷團隊，席位費約 $800→$300，但工作流程等改為點數制，整體月費約 $1,300→$3,700
- Agent 選供應商後很少回頭：Canva 沒被整合進 10K 工作流程，agent 已選 Higsfield 與 Gamma，對 SaaS 的啟示是要在 agent 選型時被選上
- 定價順序：先免費推 AI 取得採用，再用點數或計量收費（Figma 的路徑）；真正的 agent 應是 ACV 的 50–100%，例如某 3,000 萬 ARR 公司的 agent 讓 ACV 翻倍，首週採用率 3%

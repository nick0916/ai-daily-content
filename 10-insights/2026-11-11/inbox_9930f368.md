## Gemini Decisions API

Google 推出專門回答是非、選擇、評分問題的「決策模型」API，並支援影音等多模態輸入。

**What** Gemini Decision 1 與 Jev 的 API 幾乎相同，支援 yes/no、choice、rubric-scoring 三類問題，定價與 GPT-6 Luna decision model 相同（輸入每百萬 token 10 美分、輸出免費），Jev 仍最便宜（4.2 美分）。Jev 僅支援文字與 JSON，OpenAI 支援文字與圖片，Gemini 則涵蓋文字、圖片、音訊、影片與 PDF；Simon 用影片測試，Gemini 的 yes/no 回傳 0.05、0.92 等機率，而 Jev 與 OpenAI 回傳 1.0 或 0.0。

### 重點
- 定價：Gemini Decision 1 與 GPT-6 Luna decision model 同為輸入每百萬 token 10 美分、輸出免費；Jev 為 4.2 美分
- 模態：Jev 僅文字/JSON、OpenAI 文字+圖片、Gemini 涵蓋文字/圖片/音訊/影片/PDF
- yes/no 輸出差異：Gemini 回傳機率（如 robot 0.923、dragon 0.050），Jev 與 OpenAI 回傳 1.0 或 0.0

Gemini Decisions API 
Google join Jev and OpenAI in the decision model category with "Gemini Decision 1". This new model API is almost identical to Jev: it supports the same three types of questions (yes/no, choice, and rubric-scoring) and even reuses Jev's term "Noul" for a yes/no question. 
 It's priced the same as the GPT-6 Luna decision model: 10 cents per million input tokens, and output is free. Jev remains the cheapest of the three, at 4.2 cents per million. 
 Jev is text (and JSON) only. OpenAI can handle text and images. Gemini Decision 1 is fully multi-model: it covers text, images, audio, video, and PDFs. 
 I tested it against video by passing these questions to it along with my Yonkers stomping robot video file: 
 dragon: Does this video have a dragon in it?
robot: Does this video have a robot in it?
france: Is this video set in France?
usa: Is this video set in the USA?
 
 Jev and OpenAI both return 1.0 or 0.0 for yes/no questions, but Gemini insists on being a little less confident than that:

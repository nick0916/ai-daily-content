## Claude Code + Obsidian: My family’s AI brain

把全家的資料存成 Markdown，讓 Claude Code 隨時讀寫，AI 就能記得並協助處理家務。

**Why** 網頁版 ChatGPT 或 Claude 到底記得什麼並不透明，且長對話容易偏離，使用者難以確認 AI 的建議是建立在自己的真實資料上。

**How** 改用 Claude Code 這類 coding agent 讀寫本機的 Markdown 檔（搭配 Obsidian），新對話也能引用同一批檔案；另有檢查腳本防止待辦檔變冗長，專案檔收集資訊與檢查清單。

**What** Scott Ferrar 在 How I AI 展示他的家庭 Obsidian vault：電器序號與保固、待辦清單（含優先度與成本估計）、保險報價專案、地震準備等。他與太太透過 Dropbox 共享（部分腳本用 GitHub），並用腳本把待辦與旅行資訊輸出到 DAKboard 牆面顯示；他也指出在數學教育中要讓學生保有思考的主導權。

### 重點
- 做法：用 Claude Code 讀寫本機 Markdown 作為透明的記憶來源，檔案包含電器清單與序號、待辦（優先度/成本）、專案檔與想法 backlog
- 多人協作取捨：先用 Dropbox 共用資料夾（可能有同步衝突），GitHub 對家人太繁瑣，最後採 Dropbox 為主，少數腳本用 GitHub
- 實際效益：保險專案能列出下一步與阻塞點（如該寄信給誰），待辦輸出到 DAKboard 牆面；他說積壓清單被消化到「球在別人手上」

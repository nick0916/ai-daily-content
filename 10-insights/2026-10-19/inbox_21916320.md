## Buildkite Adds Scoped Secrets and New Agentic CI Tools

CI 平台 Buildkite 讓機密只對特定 pipeline 開放，並提供 MCP 工具讓 AI 協助檢查與修復 pipeline。 **What** Buildkite 新增 pipeline-scoped secrets，以及用於驗證 pipeline、診斷失敗 build、修復 webhook 的 Model Context Protocol 工具。同時為 GitHub Actions 相容層加入 Linux arm64 支援，並在 Buildkite Agent v4.1.0 擴充 OpenTelemetry 資料。

### 重點
- 新增 pipeline-scoped secrets（機密限定於特定 pipeline）
- 新增 MCP 工具：驗證 pipeline、診斷失敗 build、修復 webhook
- GitHub Actions 相容層支援 Linux arm64；Buildkite Agent v4.1.0 擴充 OpenTelemetry 資料

Continuous integration provider Buildkite has introduced pipeline-scoped secrets and new Model Context Protocol tools for validating pipelines, diagnosing failed builds and repairing webhooks.

## v3.57.1 — env-denylist hardening + native bundle drift fix

收緊 Ruflo CLI 的環境變數黑名單，補上先前漏掉的憑證與直譯器注入變數。

**Why** 2026-09-21 的 env 清理修正未涵蓋 GIT_ASKPASS、PERL5OPT 等變數，這些變數仍可能被用來劫持指令或注入直譯器參數。

**How** 擴充 DENYLISTED_ENV_NAMES，並以新 regex 攔截 git 的 GIT_CONFIG_(COUNT|KEY_\d+|VALUE_\d+) 系列變數。

**What** 版本 3.57.1，cli-core 3.7.4 鎖定版本發布；同時重建 adr/ddd/sparc 的 codex-mod native hook bundle，修復每次 push 到 main 都失敗的 native-bundle-drift 問題，並讓建置腳本在 Windows 不再因 .cmd shim 而硬失敗。

### 重點
- DENYLISTED_ENV_NAMES 新增 GIT_ASKPASS、GIT_PROXY_COMMAND、GIT_CONFIG_NOSYSTEM、PERL5OPT、RUBYOPT、JAVA_TOOL_OPTIONS、_JAVA_OPTIONS、JDK_JAVA_OPTIONS、PYTHONHOME、CLASSPATH、PYTHONSTARTUP 等變數
- 以新 regex 涵蓋 git 編號式的 GIT_CONFIG_COUNT、GIT_CONFIG_KEY_n、GIT_CONFIG_VALUE_n 變數
- 重建 adr/ddd/sparc codex-mod native hook bundle，修復 all-plugins-smoke 在 push main 時的失敗；build-codex-mod-hooks.mjs 不再於 Windows 因 execFileSync 無法直接呼叫 .cmd 而硬失敗

 Fixed

## AWS Launches TorchNeuron to Run PyTorch Models on AWS Trainium Without Modifications

讓原本寫給 NVIDIA GPU 的 PyTorch 程式，幾乎不用改就能在 AWS 自家晶片上跑。

**What** Amazon 在 PyTorch Conference North America 2026 發表 TorchNeuron，這是原生 PyTorch backend，讓開發者幾乎不需修改現有 PyTorch 程式碼，就能在 AWS Trainium AI 晶片上執行。

### 重點
- TorchNeuron 是 AWS Trainium 的原生 PyTorch backend
- 宣稱現有 PyTorch 程式碼幾乎無需修改即可執行
- 於 PyTorch Conference North America 2026 發表

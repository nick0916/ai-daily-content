## Stop Doing Agent Archaeology on Your Team's Code - Richard Feldman, Delta

讓團隊成員與 AI agent 在同一條對話串裡協作，交接時不必再靠猜測還原脈絡。

**Why** 現在每個人各自和 agent 對話，交接時只剩 issue 描述、commit 快照與貼上的逐字稿，決策理由與嘗試過的方向都遺失，被迫做「agent 考古」。

**How** 把對話、程式碼變更、留言、code review 放在同一個共享 thread，用 @mention 把同事拉進來，agent 可讀到完整脈絡；本機有 Delta worktree 鏡像，終端輸出即時同步（對方無法遠端輸入）。

**What** Delta 是 Richard Feldman 團隊做的原生協作 app（macOS/Linux/Windows/行動版，私測中、目前免費、定價未定），模型與 harness 不限（Opus 5.5、ChatGPT 訂閱，Claude Code plugin 開發中）。團隊內部已不用 pull request，改在 Delta 內跑 CI 並 land，每日站會 30–40 人同一 thread 未出問題；另有首個 on-premises 試點。

### 重點
- 交接缺少的是「決策理由與嘗試過的方向」，只靠 issue、commit、逐字稿會逼人做 agent 考古
- Delta 把對話與程式碼變更放同一 thread，可 @mention 同事、行內 review、sub-thread 隔離上下文，新加入者可請 agent 摘要整串
- 內部已取代 PR 流程：agent 跑 CI 後直接 land，並有 SOC 2 用的簽核流程；30–40 人同 thread 站會無問題

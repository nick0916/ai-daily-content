## ChatGPT Enterprise now available in AWS Marketplace

ChatGPT Enterprise 現在可以直接用 AWS 帳單買，不用另外走採購流程。

**Why** 企業採購新軟體常卡在新增供應商與簽約流程。

**How** 透過 AWS Marketplace 上架，沿用企業既有的 AWS 採購與計費關係。

**What** OpenAI 宣布 ChatGPT Enterprise 已上架 AWS Marketplace，協助組織簡化採購。

### 重點
- ChatGPT Enterprise 上架 AWS Marketplace
- 可沿用既有 AWS 採購與帳單關係，簡化企業採購流程

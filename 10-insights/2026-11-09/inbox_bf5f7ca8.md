## Teach Your AI Agent to Build Products Everyone Can Use - Jemima Abu, CAIS

用一份 accessibility skill 規範 AI agent，讓它從一開始就產出人人能用的網頁程式碼。

**Why** 96% 的前百萬網站有無障礙問題，AI 從人類既有程式碼學習，會複製偏見；它還偏好熱門但冗長的寫法，事後補 aria 就像把藍莓塞到原味馬芬上。

**How** 先定義無障礙需求、審查既有 codebase、建立 design system 讓一處修正全站生效，再用 skill 強制 agent 遵守（語意化 HTML、鍵盤可操作、優先用原生元素如 details、popover）。

**What** 講者 Jemima Abu 讓 agent 從 Figma 實作同一設計，加了 accessibility skill 後耗時由 15 分鐘降到 5 分鐘、成本降 58%，但她明說這是單次非受控實驗、不是實證數據。另推薦 Chrome/Google 的 modern web guidance skill，並提醒即使如此也不保證 100% 無障礙。

### 重點
- 單次實驗：加入 accessibility skill 後，agent 實作 Figma 設計由 15 分鐘縮到 5 分鐘、成本降 58%（講者自述非受控實驗）
- 落實四步驟：定義需求、審查現有 codebase（壞程式碼會被 agent 當標準）、建立 design system、用 skill 強制 agent 遵守
- skill 內容要引導 agent 選最佳而非最熱門的做法，如用 HTML details 取代自寫 JS accordion、用 popover 取代自製 modal

## Training Your Own Agent Models With RL Is Now Practical - Jason Mancuso, Modal

用自己線上 agent 的真實失敗案例當訓練題，以更穩定的 RL 配方微調開源模型，並把推論 GPU 分散到全球各雲端以降低成本。

**Why** 只靠換最新模型難以在 agent 成本與體驗上建立差異；SFT 只學過去記錄的單一路徑，agent 對話有分支結構，部署後容易遇到沒學過的分支；非同步 RL 又因 rollout 舊版本（staleness）與訓練端和取樣端的系統差異而不穩定。

**How** 在 GRPO 之上加 masked importance sampling（修正 token 層級落差）、score centering（移除累積漂移）、top-p 搭配 mask replay（避免稀有 token 造成災難性落差）；並利用 RL 權重更新極度稀疏（約 100 到 1000 倍）的特性，用現成壓縮把傳到 rollout 引擎的資料量降到約千分之一，使推論 GPU 能放到訓練叢集之外。

**What** Modal 的 Jason Mancuso 在 Qwen 3.6 35B（MIMO code 環境）上做消融實驗，這套配方訓練更穩定。訓練叢集在 GCP，rollout 分散在各家 hyperscaler 與 neocloud，混用多種 GPU 與 H200 的 BF16／FP8 量化，造成最多 4 到 5 倍的落差，訓練獎勵與梯度範數仍與同質設定一樣穩定，且 rollout 成本便宜 15%。部落格已發，原始碼將基於 Miles 與 SGLang 釋出。講者為 Modal 員工，結果為其自家實驗。

### 重點
- RL 配方：GRPO + masked importance sampling + score centering + top-p 搭配 mask replay；使用 top-p 時 score centering 的漂移修正是精確而非近似
- RL 權重 delta 稀疏約 100x 到 1000x，現成壓縮即可把訓練端到 rollout 端的傳輸量降到約千分之一，使推論 GPU 可放到叢集外
- Qwen 3.6 35B 實驗：跨多雲與多種 GPU（含 BF16/FP8 H200）混合 rollout，落差達 4 到 5 倍仍穩定，rollout 成本降 15%
